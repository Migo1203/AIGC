# 小度音箱视觉制作结果

用于保存本项目的产品基准图、主视觉、场景图和后续修改版本。当前仅建立目录，尚未上传制作结果。

## 建议命名

| 文件名 | 内容 |
| --- | --- |
| `product-reference-v01.png` | 白底或浅底产品基准图，中间制作素材 |
| `kv-v01.png` | 产品主视觉 |
| `home-scene-v01.png` | 居家场景 |
| `picnic-scene-v01.png` | 轻出行场景 |

修改版本继续使用 `v02`、`v03` 等后缀，便于对照迭代。上表是命名建议，不表示这些文件已经生成。

## 上传

在本文件夹点击 **Add file → Upload files**，选择图片后点击 **Commit changes** 保存。上传后在[项目制作记录](../README.md#制作记录)中补充实际结果。
