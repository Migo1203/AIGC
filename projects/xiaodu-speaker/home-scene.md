## 画面任务

用真实的阅读桌面表达日常音乐陪伴。加入书本、书签与铅笔，使画面具有生活情境，区别于第一张以产品为中心的空台面主视觉。

| 项目 | 本轮方案 |
| --- | --- |
| 画幅 | 竖版2:3，目标1024×1536 |
| 色彩与光线 | 暖米色、浅木色、少量低饱和绿色；左侧柔和窗光 |
| 构图 | 书本在左下，音箱在右下，同一桌面，二者与镜头距离接近 |
| 尺度参照 | 常见A5书本长边约21cm，音箱宽度视觉上约为其五分之二；这是构图尺度安排，不新增产品规格 |
| 画面占比 | 书本长边约占宽度55%，音箱约占22%，保留小体积观感 |
| 排版留白 | 上方约三分之一保持干净墙面，本轮不生成标题 |
| 后续文案 | 给日常，添一点音乐 |

## 实际制作输入

本轮由Codex使用`image_gen`制作场景预览。输入为[已上传v03](outputs/海报排版/音箱-窗边海报-局部修正样图-v03.png)和[顶部按键实物N02](../../assets/products/speaker/images/实物照片/音箱-顶部按键-N02.jpg)，前者只作产品外观、光线与系列基调参照，后者作结构补充。输入海报上的文字不进入新无字底图。

## 检查要点

1. 音箱保持手掌大小，与书本有合理比例，不前置放大。
2. 左竖条、右折角图案、顶部双键和浅色圆润机身保持一致。
3. 音箱、书本与台面接触自然，阴影方向统一。
4. 上方留白可供排版，书封和背景无可读文字。
5. 第一轮先检查场景构图与产品一致性，再进入文字排版。
