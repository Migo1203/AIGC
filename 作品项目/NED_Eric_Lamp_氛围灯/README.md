# NED Eric Lamp｜美国站电商视觉作品集项目

**状态：** 已完成项目启动、基础资料研究和主视觉方向规划，并生成营销主视觉 V01 供审阅，后续继续准备素材与试排。此前做过但尚未完成；现有资料以用户上传的图片为主。
