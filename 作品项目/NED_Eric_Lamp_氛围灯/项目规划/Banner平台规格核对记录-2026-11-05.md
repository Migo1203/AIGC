# NED Eric Lamp｜Banner 平台规格核对记录

核对日期：2026-11-05。用途：支持[独立 Banner 制作规划](独立Banner设计与制作规划-v0.1.md)。以下官方规则与项目设计建议分别记录；未进行 Amazon 后台上传或实机测试。

## 1. Brand Stores

来源：[Amazon Ads — Stores creative guidelines](https://advertising.amazon.com/resources/ad-specs/stores)。本次通过网页正文提取核对 Header、Image tile 与 Image with text tile 部分。

| 官方页面信息 | 本项目应用 |
| --- | --- |
| Hero image 最低 3000 × 600 px，最大 5 MB | BN01 使用 3000 × 600 px；不是任意站内横幅统一尺寸 |
| Hero 在部分情况会左右各裁掉 15%，关键部分应在中央安全区 | 3000 px 宽对应 X = 450–2550 px；属于按官方比例计算，不是后台给出的绝对坐标 |
| 页头包括 Hero、品牌 Logo 和导航；Logo 在导航中充当首页入口 | 不在 Hero 内画独立购买按钮；Logo 与背景分开规划 |
| Stores Logo 最低 400 × 400 px，最大 5 MB | 准备可用的高清标识；现有小尺寸图不靠加大画布冒充清晰度 |
| 全宽 Image with text / Text over image 最低 3000 × 1500 px | BN02 选定此布局，电脑素材使用该尺寸 |
| Text over image 可使用 prefix、heading、body、link text 等原生字段，并链接到 Store 或商品详情页 | BN02 图片与文案分开；最终字段与手机展示在编辑器检查 |
| 普通 Image tile 可以选择自定义手机图与布局；某些文字字段在该选项下只显示于电脑 | 不能推断所有 Image with text 布局都具备同样的独立手机栏；BN02 手机图先作备选资产，按实际支持导入 |
| 普通全宽 Image tile 的手机图最低宽度 1680 px；高分辨率推荐宽 3000 px | BN02 的 1680 × 1680 手机备选是项目选择，不冒充所选图文布局的统一手机规格 |
| 不鼓励把文字压入普通图片，推荐 Image with text | 店内模块优先原生文字，减少无障碍和移动阅读问题 |
| 带 link title 的矩形普通 Image tile 底部约 19% 被覆盖，方形约 12% | 仅后续切换到该类 tile 时使用；不用于统一推导所有 Banner 安全区 |

本次不选择 Shoppable image；该类型的尺寸、互动热点和产品数量规则不套用到 BN02。Hero 也不按普通内容图片的手机规格制作。

## 2. 广告：Amazon DSP Responsive eCommerce Creative（REC）

来源：[Amazon Ads — eCommerce display creatives](https://advertising.amazon.com/resources/ad-specs/ecommerce)。本次核对 Brand logo guidelines、Headline guidelines 和 Guidelines for Custom Images for Responsive Sizing。

| 官方页面信息 | 本项目应用 |
| --- | --- |
| 推荐三种自定义图片：1200 × 1200（1:1）、900 × 1600（9:16）、1200 × 628（约 1.91:1） | BN03 准备 3 个独立构图；不把它们称为最终显示广告位尺寸 |
| 响应式自定义图不使用固定安全区，图片按提供内容使用并由系统缩放 | 保留完整主体与自然边距；不挪用固定尺寸广告的绿色安全区 |
| 自定义图片不加入文字、Logo、CTA，不使用白底或透明底；不含价格与节省金额宣称 | 生活方式图片与标题、品牌组件分开；无字图片独立导出 |
| 不允许图片内 CTA 按钮或文字；需要时使用电商创意自带 CTA | 不绘制假购买按钮到图片，不把完整预览截图当上传素材 |
| 禁止挤压、拥挤、错误裁切、黑边或白边硬凑比例，且不得与落地页矛盾 | 横 / 方 / 竖分别重构，保持同款颜色与产品身份 |
| 标题最多 50 字符；不含无依据最高级、价格促销或强迫式表达 | 草案“Cordless Light for Everyday Spaces”为 34 字符（含空格） |
| Logo 至少 600 px 宽、100 px 高；最大 1000 KB；JPG / GIF / PNG | 向高清或矢量品牌原件准备；不把 Stores 的 400 × 400 规则当成 REC 的唯一规则 |
| 固定尺寸自定义广告有另一套专用 PSD 模板与安全区 | 本次先采用响应式路径；将来改为固定版位，另核模板与尺寸 |

官方响应式 PSD 模板链接：[REC Custom Image Template](https://m.media-amazon.com/images/G/01/AdProductsWebsite/images/ad-specs/REC_CustomImage_Template_2024.psd_1_3.zip)。本次仅记录官方链接，未下载、改写或验证模板内容。

## 3. 项目判断与适用边界

- “3 个创意、6 份适配资产”是本次交付范围，不是亚马逊要求每个产品都做此数量。
- “窗边安静时刻”、配色、DM Sans、坐标、字级、场景与文案是项目设计选择，不是 NED 官方 VI 或平台承诺。
- 页头手机端先检查同一 Hero 的裁切；不能把所有 Banner 概括为电脑、手机各上传一张。
- BN02 手机备选与独立文字区用于适配方案，最终采用所选模块真正支持的方式。
- 广告标题计数按草案字符串含空格计算，正式编辑时重新核对；没有进行账户资格、ASIN、素材使用许可或平台审核。
- 网页规则会调整，实际制作导出和正式上架前均应以当时编辑器、目标站点和对应广告格式为准。本记录不是“平台合规已通过”的结论。
