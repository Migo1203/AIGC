# Amazon Premium A+｜V02 规划规格摘录

读取日期：2026-11-07。来源：[Amazon 官方模块文档](https://developer-docs.amazon.com/sp-api/docs/a-plus-premium-modules)。以下是本次已读取页面的相关字段摘录；不是卖家后台导出，也不验证账号资格。文档提取器插入的 undefined 标记已去除，未改写数值。页面提取的表格中枚举分隔竖线可能拆成多列，应结合官方页面核对。

## PremiumFullBackgroundImageModule



[](https://developer-docs.amazon/sp-api/docs/a-plus-premium-modules#premiumfullbackgroundimagemodule)

JSON

```json
"contentModuleType": "PREMIUM_FULL_BACKGROUND_IMAGE"
```

A full-width background image that spans the entire module width, with optional headline and body text below.

**Recommended use cases:**

*   Close-up of product
*   Customer using the product to show size/dimension of product or in a lifestyle setting
*   Brand logo

#### Fields

[](https://developer-docs.amazon/sp-api/docs/a-plus-premium-modules#fields-1)

| Field | Type | Required | Constraint | Description |
| --- | --- | --- | --- | --- |
| `desktopImage` | `ImageComponent` | Required | min 1464w × 600h px | Full-width background shown on desktop. |
| `mobileImage` | `ImageComponent` | Required | min 600w × 450h px | Background shown on mobile devices. |
| `headline` | `TextComponent` | Optional | value: max 80 chars | Headline text located above the image. |
| `footer` | `ParagraphComponent` | Optional | textList: 1–4 items; total < 301 chars | Text below the image. Up to 4 lines; combined length must not exceed 300 characters. |



## PremiumFullBackgroundTextModule



[](https://developer-docs.amazon/sp-api/docs/a-plus-premium-modules#premiumfullbackgroundtextmodule)

JSON

```json
"contentModuleType": "PREMIUM_FULL_BACKGROUND_TEXT"
```

A full-width background image with a text overlay box containing a subheadline, headline, and body text. The text box can be positioned to the left or right, and styled light or dark. On mobile, the text overlay is removed and the image stacks above the text content.

**Recommended use cases:**

*   Close-up of product
*   Customer using the product to show size/dimension of product or in a lifestyle setting
*   Highlight key product features/benefits — think product "elevator pitch"

#### Fields

[](https://developer-docs.amazon/sp-api/docs/a-plus-premium-modules#fields-2)

| Field | Type | Required | Constraint | Description |
| --- | --- | --- | --- | --- |
| `positionType` | `PositionType` | Required | `LEFT` | `RIGHT` | Side of the image on which the text overlay box is anchored. |
| `colorType` | `ColorType` | Required | `DARK` | `LIGHT` | `DARK` produces a semi-opaque grey overlay with light text; `LIGHT` produces a semi-opaque white overlay with dark text. |
| `desktopImage` | `ImageComponent` | Required | min 1464w × 600h px | Full-width background shown on desktop. |
| `mobileImage` | `ImageComponent` | Required | min 600w × 450h px | Background shown on mobile devices. |
| `subheadline` | `TextComponent` | Optional | value: max 40 chars | Short eyebrow label rendered above the headline in the text overlay. |
| `headline` | `TextComponent` | Optional | value: max 60 chars | Primary headline text displayed in the overlay box. |
| `description` | `ParagraphComponent` | Optional | textList: 1–2 items; total ≤ 300 chars | Supporting body copy in the overlay. Up to 2 lines; combined length must not exceed 300 characters. |



## PremiumImageCarouselModule



[](https://developer-docs.amazon/sp-api/docs/a-plus-premium-modules#premiumimagecarouselmodule)

JSON

```json
"contentModuleType": "PREMIUM_IMAGE_CAROUSEL"
```

A carousel of full-width image panels, each with its own headline and body text. Users swipe or click through panels. On mobile, title and headline appear above the image, and description appears below.

**Recommended use cases:**

*   Close-up of product
*   Customer using the product to show size/dimension of product
*   Highlight key product features/benefits — think product "elevator pitch"
*   Show feature or use case differences between products in your catalog

#### Fields

[](https://developer-docs.amazon/sp-api/docs/a-plus-premium-modules#fields-6)

| Field | Type | Required | Constraint | Description |
| --- | --- | --- | --- | --- |
| `headline` | `TextComponent` | Optional | value: max 80 chars | Headline displayed above the carousel. |
| `footer` | `ParagraphComponent` | Optional | textList: 1–4 items; total ≤ 300 chars | Footer text placed below the carousel. |
| `carouselCards` (2–6 items) | `array` | Required |  | Ordered list of carousel slides. |
| `position` | `integer` | Required | 1–6; unique per carousel | Display order of this slide. Each panel must have a distinct value. |
| `title` | `TextComponent` | Optional | value: max 50 chars | Short title within the image overlay. |
| `buttonText` | `TextComponent` | Optional | value: max 12 chars | Call-to-action button label (for example, "Shop Now"). Only shown when asin is also provided. |
| `asin` | `TextComponent` | Optional | value: exactly 10 chars | Amazon product ASIN for the button link. Exactly 10 alphanumeric characters. |
| `description` | `ParagraphComponent` | Optional | textList: 1–4 items; total ≤ 200 chars | Supporting text overlaid on the slide. |
| `desktopImage` | `ImageComponent` | Required | min 1464w × 600h px | Full-width background shown on desktop. |
| `mobileImage` | `ImageComponent` | Required | min 600w × 450h px | Background shown on mobile devices. |



## PremiumNavigationCarouselModule



[](https://developer-docs.amazon/sp-api/docs/a-plus-premium-modules#premiumnavigationcarouselmodule)

JSON

```json
"contentModuleType": "PREMIUM_NAVIGATION_CAROUSEL"
```

A carousel of full-width image panels with clickable navigation tabs. Each panel has its own navigation text, subheadline, headline, and body text.

**Recommended use cases:**

*   Show feature or use case differences between products in your catalog
*   Upsell opportunity for other products that may be of better value
*   Photos of all angles of the product
*   Show different uses of the product

#### Fields

[](https://developer-docs.amazon/sp-api/docs/a-plus-premium-modules#fields-7)

| Field | Type | Required | Constraint | Description |
| --- | --- | --- | --- | --- |
| `carouselCards` 2–5 items | `array` | Required |  | Ordered list of navigation carousel slides. |
| `position` | `integer` | Required | 1–5; unique per carousel | Display order of this slide. Each panel must have a distinct value. |
| `navText` | `TextComponent` | Required | value: 1–25 chars; not blank | Tab label shown in the navigation strip. Must not be blank. |
| `desktopImage` | `ImageComponent` | Required | min 1464w × 600h px | Full-width background shown on desktop. |
| `mobileImage` | `ImageComponent` | Required | min 600w × 450h px | Background shown on mobile devices. |
| `title` | `TextComponent` | Optional | value: max 50 chars | Large heading overlaid on the slide image. |
| `subtitle` | `TextComponent` | Optional | value: max 25 chars | Smaller subheading below the title. |
| `description` | `ParagraphComponent` | Optional | textList: 1–4 items; total ≤ 100 chars | Supporting copy overlaid on the slide. |



## PremiumHotspotImageModule



[](https://developer-docs.amazon/sp-api/docs/a-plus-premium-modules#premiumhotspotimagemodule)

JSON

```json
"contentModuleType": "PREMIUM_HOTSPOT_IMAGE"
```

A full-width image with clickable hotspot markers that reveal headline and descriptive text for each point of interest.

**Recommended use cases:**

*   Simplify and structure feature/benefit callouts for complex, feature-heavy products
*   Answer questions like "What does this button do?" and "What does this material look and feel like?"

#### Fields

[](https://developer-docs.amazon/sp-api/docs/a-plus-premium-modules#fields-12)

| Field | Type | Required | Constraint | Description |
| --- | --- | --- | --- | --- |
| `desktopImage` | `ImageComponent` | Required | min 1464w × 600h px | Full-width background image on which hotspots are placed. |
| `hotSpots` (2–6 items) | `array` | Required |  | Interactive hotspot markers placed over the desktop image. Each item wraps an `imageHotSpot` object. |
| `title` | `TextComponent` | Required | value: 1–50 chars | Label shown when the hotspot is activated. |
| `xCoordinate` | `TextComponent` | Required | string pixel value (for example, "25") | Horizontal pixel position of the hotspot on the desktop image. |
| `yCoordinate` | `TextComponent` | Required | string pixel value (for example, "150") | Vertical pixel position of the hotspot on the desktop image. |
| `mobileImage` | `ImageComponent` | Required | min 600w × 450h px | Detail image shown when this hotspot is activated on mobile. |
| `description` | `TextComponent` | Optional | value: max 200 chars | Descriptive text shown alongside the hotspot label. **Note:** this is a `TextComponent` , not a `ParagraphComponent` . |

**Recommended use cases:**

| `mainDescription` | `ParagraphComponent` | Optional | textList: 1–2 items; total ≤ 300 chars | Supporting copy displayed below the headline. |
| `desktopImage` | `ImageComponent` | Required | min 1464w × 600h px | Full-width background image on which hotspots are placed. |
| `hotSpots` (2–6 items) | `array` | Required |  | Interactive hotspot markers. Each item wraps an imageTextHotSpot object. No description field per hotspot, unlike `PremiumHotspotImageModule` . |
| `title` | `TextComponent` | Required | value: 1–50 chars | Label shown when the hotspot is activated. |
| `xCoordinate` | `TextComponent` | Required | string pixel value (for example, "25") | Horizontal pixel position of the hotspot on the desktop image. |
| `yCoordinate` | `TextComponent` | Required | string pixel value (for example, "150") | Vertical pixel position of the hotspot on the desktop image. |
| `mobileImage` | `ImageComponent` | Required | min 600w × 450h px | Detail image shown when this hotspot is activated on mobile. |



## PremiumFaqModule



[](https://developer-docs.amazon/sp-api/docs/a-plus-premium-modules#premiumfaqmodule)

JSON

```json
"contentModuleType": "PREMIUM_FAQ"
```

A list of question-and-answer pairs with a configurable background color scheme of light or dark.

**Recommended use cases:**

*   Proactively answer frequently asked questions
*   Address common concerns that lead to customer complaints or returns

#### Fields

[](https://developer-docs.amazon/sp-api/docs/a-plus-premium-modules#fields-14)

| Field | Type | Required | Constraint | Description |
| --- | --- | --- | --- | --- |
| `colorType` | `ColorType` | Required | `DARK` | `LIGHT` | Background color scheme. `DARK` produces a dark background with light text; `LIGHT` produces a light background with dark text. |
| `faqs` 2–5 items | `array` | Required |  | List of FAQ entries. Each item wraps a faq object. |
| `question` | `ParagraphComponent` | Required | textList: 1 item; max 120 chars | The question text. Supports rich text decorators. |
| `answer` | `ParagraphComponent` | Required | textList: 1–5 items; total ≤ 250 chars | The answer text. Up to 5 paragraphs; combined length must not exceed 250 characters. Supports rich text decorators. |
