# 作品集「04_Banner系统」内容与展示规划 V01

2026-11-08。作品集外层延续V04，内容候选为独立Banner V02，本文件为展示规划V01。当前待用户审阅，不代表已制作正式04展示段，也不代表Banner原素材已定稿或实际投放。

## 1. 本段的任务

03品牌故事已说明品牌来历、审美与生活方式。04段进一步展示：同一盏Eric，如何在店铺页头、餐桌导流与广告入口中承担不同任务，同时维持产品识别、自然材质和光线气质。

推荐标题：**Banner系统 / 不同入口，同一种光**。副句：**从认识Eric，到餐桌导流，再到夜间广告。** 这是作品集对交付分工的解释，不是品牌官方口号或经过验证的转化结论。

主内容按“认识产品 → 场景入口 → 广告利益”组织。本段展示Banner系统成果，V01／V02的完整前后对比留到后续迭代段；不在这里重复堆一套历史版本。

## 5. 正式展示的取舍

- **主展保留六份适配。** 方图和竖图逐张可查看；横图示范组件关系后，方／竖无需再重复同一句广告标题三遍。原文案、图片和Logo依旧分别交付。
- **中央裁切作为辅助检查。** 规划稿已显示，正式版保留较小检查区并说明用途；不包装成新增手机版本。若版面需压缩，先缩短外层说明，不删六份主体适配。
- **迭代证据另成段。** 后续挑页头与餐桌两组同尺寸V01／V02对照，说明移除白色覆盖、标题聚焦、场景保留等可观察变化；本段只简短解释各入口职责。
- **已有素材优先。** 暂无新增生图必要。先解决排版、裁切和局部问题；不为每个比例再生成不同产品或新场景。

## 6. 制作重点与质量门槛

| 项目 | 正式制作动作与通过条件 |
| --- | --- |
| 产品底座与身份 | 逐张检查六份素材及展示缩放：旋钮、灯罩、细杆、底座比例不走样；区分接触阴影与不合理厚黑条，发现问题再局部修复，不沿产品轮廓描黑线 |
| BN02文字对比 | 现图深色文字位于棕色墙面上；在实际展示尺寸复核标题、说明和入口，必要时仅调文字位置／颜色或小范围背景明暗，不直接加回大面积白罩 |
| 页头裁切 | 完整图和中央裁切分别检查文字、灯体及承托；不改变产品横纵比例，不把现有中央裁切等同所有手机设备适配 |
| 手机图文 | BN02用独立素材，文字放相邻字段；长句按实际宽度断行，入口可读，图文不互相遮挡 |
| REC关系 | 横图展示图文关系，方／竖保留无字图片；Logo和标题作为独立对象，避免虚构广告平台UI、价格、按钮或已投放身份 |
| 可编辑性 | 正式长图复用原三份SVG的文字／线条，补齐品牌栏和手机字段为独立对象；Logo使用现有轮廓路径，照片仍是位图 |
| 连续背景与导出 | 与03段背景边界匹配，投影只作用于模块外框；检查最后竖图底座和页尾，超长总览必要时分块导出后拼接 |
| 来源与分辨率 | 原素材存在插值和场景复用；不把3000px输出宽度称为3000px原生摄影细节，不改写为全新生成或实拍 |

本轮只做规划，尚未执行上述文字调整或产品修图，不能将“列入检查”写成“已修复”。V02照片可作为排版候选，不因旧交付检查记录而自动判定当前展示质量全部通过。
