# 参考示范

小度音箱项目的Codex示范样图统一保存在本文件夹，共5张，均为1024×1536像素的PNG。图片内容、尺寸和格式保持原样；历史版本保留作过程对照。

本目录文件名统一以 `Codex示范-` 开头，便于与用户上传稿区分；既有版本号保持不变。该标记只说明来源，图片可直接被选用于项目；选用时引用原文件，不重传或复制。
