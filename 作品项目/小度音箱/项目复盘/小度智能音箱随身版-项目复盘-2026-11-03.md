# 小度智能音箱随身版｜项目复盘

记录日期：2026-11-03。项目为独立制作的国内电商视觉与求职作品集练习，非品牌委托；当前未绑定具体电商平台，也没有实际投放与转化数据。

## 一、项目结论

项目已从单张海报练习，推进到具有统一视觉方向的主图、海报、场景和详情页套系。用户已选用7张主图、20张海报和4张使用场景图，并完成两张详情页长图的V02排版上传。主要视觉内容已经具备，进入核对与收尾阶段。

与原定完整交付相比，详情文案及接口类型仍需核对；产品精修母版、展示图的最终确认、作品集案例和源文件整理尚未全部完成。现有PNG/JPG可用于阶段检查，不等于整套已完成最终验收。

## 二、项目目标与产品依据

围绕“小度智能音箱随身版”，将用户提供的商品资料和实拍整理为一套能说明产品、卖点和使用条件的视觉内容，并形成可用于求职展示的案例。视觉主张为“日常音乐，随手带走”，方向是清爽亲和的生活数码。

本项目实际使用的主要事实与表达边界：

| 依据 | 本项目可以使用的表达 | 需要保留的边界 |
| --- | --- | --- |
| 产品尺寸及重量 | 资料标称约80×57mm、约96g | 资料仅给出两项尺寸；重量以实物为准 |
| 播放时长 | 约10小时播放 | 来源标注为小度实验室70%音量播放条件，实际因环境和使用习惯而异 |
| 蓝牙及助手 | 蓝牙连接手机播放；按键使用小度助手 | 助手需蓝牙连接手机并保持小度App打开，不支持“小度小度”语音唤醒；具体按压方式仍待核对 |
| 扬声器与额定功率 | 40mm全频单元、额定功率3W | 属于资料标称，不能据此推断低音领先或音质实测结果 |
| 充电接口 | 商品参数图标注USB Type-C | 后补背部实拍轮廓存在疑点，接口实际类型需结合实物插头或说明书确认 |
| 使用环境及配件 | 资料提示无防水功能；版本及配件按所选SKU确认 | 不暗示防水，也不将不同套餐图的配件合并为统一赠品 |

## 四、已完成的主要内容

1. **建立产品事实基础。** 原始商品图与实拍分开管理，标称值、必要条件和冲突项有来源可查，减少后续排版时凭印象补参数。
2. **确定统一视觉语言。** 项目使用暖白、深灰绿、鼠尾草绿及少量淡蓝灰，结合自然侧光、浅木和生活道具；配色属于本项目选择，不宣称为品牌官方VI。
3. **让画面承担不同职责。** 便携图用手和包口建立携带关系，蓝牙图用手机及连接图形解释播放，续航图将约10小时与测试条件放在同一模块，场景图呈现日常使用。
4. **形成多种画幅素材。** 已选主图、横竖方海报和四类场景均有可查看文件；已有的产品正面、45°、侧面、顶部和背部图可作为工作参考。
5. **组装详情页排版V02。** 两张JPG已覆盖产品认知、功能总览、配置、便携、续航、助手、蓝牙、场景和选购提示。V02中场景人物服装及音箱摆放角度已有变化，减少了同色服装和同角度重复。

## 五、关键问题与复盘

### 1. 一开始把“统一”做成了“重复”

**现象：** 早期M01与M03的正面产品、位置和浅色背景相近，主要靠标题区分；M02已有场景，因此问题不是所有图片都缺少背景。

**原因：** 先固定字号、坐标和模板，后思考卖点如何被画面表达；同时把事实、排版与可读性检查过早当作完整商业视觉验收。

**调整：** 先确定每张图回答什么问题，再选择动作、产品角度、尺度关系和画面结构；统一色彩与产品身份，不要求所有图同构。后续仍需横向复核产品结构、尺度与整套节奏。

### 2. 产品条件与画面文案没有始终同步

**现象：** 详情排版初版的便携模块出现“仅约69g”，而同页参数表为约96g；用户上传的V02已改为约96g。V02仍出现“大容量锂电池”“全天候使用”“低音更有力”等缺少现有依据的表述，参数表保留了待核实的USB Type-C。

**原因：** 生成、改字和长页拼接分阶段进行，事实表没有成为每次导出前的逐项检查基准；有条件的参数容易与宣传语分离。

**调整：** 正式导出前统一核对全文数字、单位和条件。将约10小时与70%音量条件邻近呈现；接口未核实时不写死类型；40mm只作为配置，不扩展为未测量的听感优势。标称信息与真实性说明应按购买判断需要保留，而不是全部删掉。

### 3. 图组后期暴露了色彩与视角重复

**现象：** D06 V01的场景人物服装多为绿色，音箱在各格的位置和朝向相近；用户提出减少绿色元素并增加视角变化。

**调整：** 保留亲子、聚会、旅行和运动四个场景，使用米白、暖棕、浅蓝及浅紫等服装色，改变音箱在桌面或侧架上的位置，并增加正面与斜侧视角。排版V02已使用调整后的场景图；产品具体形态与比例仍应对照实拍检查。

### 4. 页面检查要覆盖整套，而不止单张

**现象：** 单张画面可读不代表拼成长图后小字仍可读；资料说明、结构示意脚注与测试条件在缩小查看时容易弱化。旧审稿也曾偏重文字、对齐和合成边缘，忽略卖点表达和图组节奏。

**调整：** 审核分三层：先核对事实和必要条件，再检查单图构图与可读性，最后按手机阅读顺序检查整套的重复、衔接、产品一致性及导出文件。设计判断不能替代真实投放或用户测试。

### 5. 归档状态需要明确区分

**现象：** 图片生成、用户选用、详情页拼接、项目文档更新和GitHub同步并非同一动作。现有部分项目索引仍写“长页待制作”，但GitHub上已经存在两张排版V02长图。

**调整：** 以实际文件、版本及审核记录为准更新索引；分别记录“候选、用户选用、已排版、待核实、最终交付”，并核对文件是否已同步到GitHub。归档不等于最终验收，扁平图片也不等于分层源文件。

## 七、分工与工作方式

- **用户：** 提供商品资料、选择与审核视觉方向和图片、提出风格及细节修改、上传并迭代详情页排版；此前已确认使用Photoshop进行部分画面调整和文字排版。
- **Codex与图像生成工具：** 整理资料、规划信息层级、生成或修改概念和候选图、依据用户反馈进行检查、维护项目记录。实际图像工具未返回具体模型版本，不推断版本号。
- **边界：** 用户上传、选用或要求归档与作者身份、最终商业验收不是同一概念；未读取到PSD时不推断字体、字号或图层结构。

## 八、下一步

1. **核对并修正详情页：** 验证充电接口；删除或改写缺少依据的音质、电池容量与“全天候”等描述，确认96g及10小时条件在相关模块一致。
2. **完成视觉终审：** 以手机宽度检查说明文字、模块节奏、图像接缝、产品结构及尺寸感；确认主图、海报和详情页的最终采用版本。
3. **整理产品及源文件：** 对照实拍确认正面、顶部、背部的可靠素材；整理已有分层文件、字体、素材来源与导出文件，不将未找到的文件记为已交付。
4. **制作作品集案例：** 用目标、产品依据、早期问题、方向选择、代表性迭代和最终应用构成案例；只写实际完成内容，不虚构转化提升或设计效率数据。
5. **核对仓库和文件清单：** 更新过时索引，确认需要保存的本地候选和最终文件，再按实际范围同步与归档。
