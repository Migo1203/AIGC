# 视觉优化、设计规范与产品依据

日期：2026-10-26。已读取指定的本地 `plan-ecommerce-visuals` 技能，并实际查看窗边v03、居家PSv02、轻出行PSv01，以及正面实拍N03、顶部按键N02。用户已选择先做作品集概念套系，暂不绑定平台；下列尺寸均为本项目设计工作画幅，不代表任何平台官方规范或可直接上架。

原三张海报的本轮通过结论保留。新任务是把已有生活方式视觉延展为能解释产品、回答购买疑问的完整电商概念套系。推荐以用户最满意的第三张为色彩与自然光参考，保留暖米色、浅木色、低饱和绿植和深绿色文字。

后续已按仓库 `ecommerce-visual-strategy v0.1.0` 复核三张海报与M01/M02，结论见[电商视觉策略](电商视觉策略.md)：主购买理由聚焦轻巧便携，蓝牙播放尽早解释，40mm仅作配置支持。下方配色和字号继续作为试排规范，不能用参数是否照搬代替审稿；现有采用稿保持，局部优化按新用途选择。

## 三项优先优化

| 优先项 | 具体位置与原则 | 操作 | 预期效果 |
| --- | --- | --- | --- |
| 1. 先建立可复用的真实产品精修素材 | 三张产品来自不同生成、取景与光影阶段，网罩清晰度、顶部按键和外壳明暗表现不同；产品真实性与重复 | 以正面实拍N03固定轮廓和正面图案，以N02核对灰色控制区与双键；先完成一张正面略俯视的干净产品精修图，保留真实结构，再从已确认的实拍制作其他展示角度。每张图复用同一套已核对产品素材，按场景匹配阴影和色温。孔纹局部形变以真实照片为依据修理，不把AI海报当唯一结构真值，也不凭虚焦实拍声称精确重建孔数 | 后续主图、卖点图、详情细节图都有稳定的产品基础，减少每张各自重造一台产品 |
| 2. 给图片分配不同信息职责 | 现有三张都以情绪口号和生活场景为主，适合营销概念；亲密性、对比与信息主次 | 保留三图承担品牌印象、居家使用、轻出行情境。新增产品展示/主图组分别回答“产品是什么”“体积/携带如何”“发声配置是什么”“怎样连接/怎样使用”“哪些条件与配件需要知道”；详情页按认知→证据→操作→场景→购买前确认编排。一张图一个主问题，把对应说明、条件与数字放在一起，文案仅使用已核实资料 | 让整套设计覆盖购买判断，而不是用多张相似口号填满交付数量 |
| 3. 分用途重排，建立移动端文字层级 | 三图为1024×1536竖版，窗边标题和主体较大，两个场景的留白较多；这与原图职责匹配。转方形商品图或详情模块时需新的对齐与对比 | 原海报与用户确认的居家近景保留；不要直接横向拉伸或机械方形裁切。方图另设1000×1000工作画布，按主信息重排产品、标题和证据；750px宽详情页使用统一侧边距和三层字体。细节与参数用干净浅底承载，绿植场景集中在氛围/使用模块，减少文字落在斑驳高光或木板接缝处。用户PS文字优先复制为统一样式，再按版式调整 | 保留原视觉气质，同时让信息在手机上清楚；不同用途有明确版式，而不是同一海报缩放多次 |

## 建议的统一视觉系统

以下为新套系起始设计规范，不是从现有PNG反查出的实际字体参数。所有字号为px；最终按文案长度、图像轮廓与缩小预览调整。

| 项目 | 建议 |
| --- | --- |
| 背景主色 | 暖米白 `#F5F0E7`；承载大段信息的浅底 `#FFFCF6` |
| 主要文字 | 深绿 `#29401C`，沿用当前标题色 |
| 正文文字 | 深灰绿 `#393A33`；次级说明 `#5A5145` |
| 辅助色 | 低饱和浅绿 `#DCE4CF`，只用于小面积标签底、编号和信息分组；不与主标题同时争焦点 |
| 字体 | 思源黑体（Source Han Sans SC）；标题Bold 700，副标题Medium 500，正文Regular 400。用户若采用其他字体，可统一替换整套，不能以PNG认定已使用此字体 |
| 方图1000×1000 | 四边起始安全边距64；主标题64–72/行距80–88，副标题32/44，正文28/40，必要条件说明22–24/32。信息型图优先左对齐，产品识别主图可居中；全套使用少量固定对齐线 |
| 详情750px宽 | 左右起始边距48，有效内容宽654；标题44–48/60，副标题30–32/44，正文26–28/38–40，条件说明22–24/32；模块标题到正文24–32，内容组间32–48，模块间64–80 |
| 竖版营销海报1024×1536 | 直接保留三张既有视觉，若制作优化版，产品名28–32、标题96–112、说明24–28作为新建文字的起始范围；优先复制用户现有PSD样式，逐张按职责调整，不要求为达到这些数值重做 |
| 图形 | 单线功能图标或简洁编号；图标只表达已核实功能。参数、条件和解释成组，避免多个角标、促销贴纸和装饰同时占主焦点 |
| 光影与材质 | 统一柔和左上方自然光的总体方向，浅色机身不过曝，保留哑光外壳和金属网罩；接触阴影随实际落点重建，不能直接把室内阴影贴到户外 |

尺寸与字号是工作起点。需要排版边界框时按单张任务卡给出X/Y/W/H，不在整套规划阶段假定所有文字位置相同；同一图内的标注不遮住产品结构和真实使用方式。

## 产品素材准备方向

1. **正面略俯视精修图**：真实正面N03为形态依据，N02补双键；用于识别主图、配置图和通用展示。
2. **控制区与接口细节**：分别从N02及真实背部接口照片取材，不从正面AI图推测背部。为展示实际操作，手部动作和手机界面必须有依据；不以装饰声波或虚构UI替代操作说明。
3. **侧面/后部展示**：若本套需要多角度展示，先使用现有对应实拍；素材不足时将该图列为待补，不让图像工具想象隐藏结构。尺寸图同样只标已确认尺寸，不从海报像素比例推算真实深度。

推荐先完成第一项产品精修并核对，再制作主图组与详情模块。保留三张原图的采用与来源记录，后续优化版另编号；本次只交付规划与任务，不生成示范图。

## 外观与生成约束

- 结构依据优先级：对应角度实拍 → 已核对产品精修素材 → 既有海报的光色参考。三张海报不作为精密结构的唯一真值。
- 本套固定浅色机身、正面左竖条与右朝左折角图案、顶部灰色控制区内两枚按键。按正面观察为左麦克风、右电源；看背面时左右会随视角反转，不能机械复制。
- 保留网罩弧面、接缝、已见接口位置和合理厚度。实拍未清晰展示的内部孔纹/接点不靠模型补造；R03若不能确认细节，先保留真实整体背部，不放大当精密接口特写。
- 基准B有蓝色亮点，精修时可按原位置保留，不扩大成灯效，不赋予配对/语音/电量状态含义。未展示挂绳安装位置的视角不要求新增挂绳或扣位。
- 可变内容是背景、道具、取景、留白、光线氛围与信息版式；改变背景后检查投影与色温。参数、功能条件、产品结构与来源关系不随创意改变。
