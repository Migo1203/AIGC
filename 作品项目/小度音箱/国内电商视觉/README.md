## 概念与信息主线

视觉：暖米白、浅木色、低饱和绿植、深绿色标题，结合干净的产品特写和清楚的参数信息。读者先认出产品，再理解便携、发声配置、播放时长和使用条件，最后完成选购判断。

2026-10-26使用仓库 `ecommerce-visual-strategy` 完成[策略复核与成图优化建议](电商视觉策略.md)。推荐定位为“书桌与干燥轻出行情境中的便携蓝牙音箱”，主购买理由是**约96g轻巧便携**；蓝牙连接手机解释基础使用方式，约10小时播放提供带条件的时长信息，40mm全频单元补充配置。不能仅凭40mm推出音质优越。

本轮受众以“在书桌与短途出行情境听手机音乐的人”描述；学生、年轻职场人仍属创意假设，深圳是求职目标，不是已经验证的消费者地域。商品名称保留，同时在详情首屏明确“便携蓝牙音箱，连接手机播放”，M05再分开普通播放与助手的App条件。

本次错误与改进状态见[集中复盘](../../../复盘记录/小度音箱/问题与改进记录.md)，后续定向和评审沿用[现有提案验证任务](../../../任务/商业视觉提案验证/README.md)。下述五图八模块是历史范围草案；编号和旧成果保留，新的信息优先级与数量按提案理由调整，不将每个参数自动设为独立卖点。

## 三项视觉优化

| 优先项 | 具体位置与原则 | 执行动作 | 达到的目标 |
| --- | --- | --- | --- |
| 统一产品素材 | 三海报的网罩清晰度、按键表现及光色有差别；产品真实性与重复 | 以实拍核对正面、双键和背部，先建立3张可复用精修素材；新增商品信息图复用同一组素材，再按环境匹配光影 | 产品在不同图中有稳定识别，不让每张生成结果各自改变结构 |
| 区分信息职责 | 既有三图主要承担情绪和场景表达；亲密性与对比 | 三旧图继续用作营销和场景；新增商品首图、卖点辅图及详情模块分别回答产品、配置、连接、限制和配件问题 | 每张图有一项主信息，并有对应依据 |
| 分用途重新排版 | 原海报是竖版，主图组与详情页用途不同；对齐与层级 | 方图独立安排产品、标题与证据；详情用统一网格和信息分组。保留居家近景，不直接拉伸或机械裁方 | 保留原视觉概念，同时便于移动端阅读与选购 |

这是新电商用途的优化目标，既有三张概念海报的通过记录保留；本轮不要求全部重生或强制改成相同产品占比。
