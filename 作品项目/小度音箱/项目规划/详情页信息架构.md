## 目标与阅读顺序

面向通过手机阅读详情的潜在购买者：先认出这是一款可连接手机播放的便携音箱，再理解携带、播放时长、连接和助手条件，最后看清外观、使用场景与选购信息。项目为作品集概念练习，暂不绑定具体平台；卖点顺序是本项目设计选择，并非经过消费者研究验证的结论。

**产品认知 → 轻巧便携 → 播放时长 → 手机连接与助手 → 外观细节 → 使用场景 → 配置与接口 → 选购须知**

建议做成一份有连续阅读节奏的长页：开头与场景模块用生活摄影，连接、细节和规格模块适当简化背景。统一光线、产品、色彩和文字层级，让每一屏承担不同的问题。

## 画幅与视觉系统：试排起点

以下数值用于本项目设计试排，需按实际文案、图片及手机预览调整，不是已测量的原图参数，也不是任何平台的官方上传规范。

| 项目 | 建议起点 |
| --- | --- |
| 画布 | RGB / sRGB，工作宽 **750 px**；建立可编辑长页与D01–D08分组。目标平台、实际切片和上传限制之后再按对应官方规则核对。 |
| 模块高度 | D01 900、D02 900、D03 850、D04 1200、D05 950、D06 1100、D07 1250、D08 750 px；合计约 **7900 px**。先用于排版估算，D06若改为单列需增高，最终高度按内容确定。 |
| 栅格 | 每模块以左上角为原点；内容主区域建议 **X=48、W=654 px**，左右各48 px；标题起始Y约64 px，必要说明与对应卖点靠近。图像可按构图适当突破文字边界。 |
| 文字 | 优先思源黑体SC或可用的清晰中文无衬线；主标题约56–68 px、次级信息30–36 px、说明26–30 px、必要条件24–28 px，行距约1.3–1.5倍。均为750 px宽画布上的像素起点，实际以手机预览可读为准。 |
| 色彩 | 延续项目色板：暖白 `#F3F1EA`、深灰绿 `#24352F`、鼠尾草绿 `#91A58E`；功能信息处可少量使用淡蓝灰 `#DCE8EC`。色值为项目建议，不声称是官方VI或原图取样值。 |
| 场景格 | D06若采用2×2，内容区654 px、列间距16 px，则单幅宽319 px；4:3画面可试排为约319×239 px。情境图用于讲生活场景，产品细节另由D05承担。 |
| 画面节奏 | 大产品首屏 → 手持动作 → 时长信息 → 手机与按键 → 局部细节 → 场景组 → 参数 → 简洁清单；采用相同字体与主对齐线，但不固定每屏相同构图。 |

## 资料依据与表达边界

- **重量与尺寸**：约96g、约80×57mm均来自[016参数表](../../../素材/产品资料/音箱/图片/规格与说明/音箱-配置参数表-016.jpg)，为资料标称；只提供两个尺寸，不自行补第三维。
- **播放时长**：约10小时及70%音量条件来自[005续航资料](../../../素材/产品资料/音箱/图片/商品宣传/音箱-续航宣传-005.jpg)，条件与数字放在同一模块；不写无条件“全天播放”或续航领先。
- **连接与助手**：[018连接说明](../../../素材/产品资料/音箱/图片/规格与说明/音箱-连接与使用限制-018.jpg)和[007使用条件](../../../素材/产品资料/音箱/图片/规格与说明/音箱-App与按键使用条件-007.jpg)区分普通蓝牙播放与助手的手机、App、按键条件；实际按压方式、当前App与服务可用性仍需核对。
- **40mm与3W**：[004扬声器资料](../../../素材/产品资料/音箱/图片/商品宣传/音箱-扬声器结构宣传-004.jpg)和[016参数表](../../../素材/产品资料/音箱/图片/规格与说明/音箱-配置参数表-016.jpg)标称40mm全频单元、额定功率3W；爆炸结构为概念示意，未经过拆机验证，不扩写为Hi-Fi或低音领先。
- **充电接口**：016标称USB Type-C，但[补充背部照片](../../../素材/产品资料/音箱/图片/实物照片/微信图片_20261030165738_420_46.jpg)的轮廓存在疑点，尚无法仅凭照片确定类型或对应批次；待实物插头或说明书核实后再写具体类型。
- **版本与配件**：[017包装清单](../../../素材/产品资料/音箱/图片/规格与说明/音箱-包装清单-017.jpg)与其他套餐图并非同一套清单；正式内容按实际SKU核对。完整三维尺寸、配件、型号、价格、当前兼容性与售后仍有待确认项，见[规格原表](../../../素材/产品资料/音箱/规格资料/product-specs.md)。

## 当前制作方式与检查

1. 先用D01首屏试排，确定文字、产品、光线和留白；再按D02–D08职责展开，不必默认每个模块都重新生成。
2. 已选图片均为扁平PNG，其中部分自带文字，可作构图、色彩与局部素材参考；要做可编辑详情页，应按需要重排文字、图形和背景，不能把PNG当作已有PSD图层。若需要新背景，再按缺口生成并记录实际使用素材。
3. 以[已选产品多视角图](../产品多视角图)保持外观方向，用实拍核对正面图案、顶部双键及背部接口；统一产品颜色、光线、尺度和接触阴影。
4. 按模块保存可编辑文件或分组，完成长页后再依目标平台规则切片。以手机尺寸检查标题、参数条件、四场景主体和模块衔接；同时复核产品结构、资料来源和全部文案。
