## 1. 项目在做什么，为什么这样做

本项目把“小度智能音箱随身版”的用户提供资料、真实外观和已审核的新视觉概念，整理成**用于求职作品集的独立商业视觉概念套系**。目标是让读者依次理解“它是什么 → 为什么便于日常携带 → 如何播放手机音乐 → 使用和购买时要确认什么”，同时展示资料分析、视觉决策、素材制作和信息设计之间的关系。

**采用的美术方向：清爽亲和的生活数码；核心主张：日常音乐，随手带走。** 用户已通过[便携、居家、手机连接三张VI概念](../视觉概念/VI概念提案-2026-10-28/README.md)。本轮实际打开三图复核，沿用自然光、深灰绿标题、灰绿弧线、浅色生活材质及淡蓝灰功能页。三图证明用户认可这一视觉效果；正式产品母版、精确尺度、可编辑排版和最终应用仍须制作。

项目的因果主线是：**资料标称约96g、手机蓝牙播放等事实 → 推导日常携带与使用理解的购买理由 → 用手持尺度、生活承托、手机到音箱的路径表现 → 分配给海报、电商主图及详情模块。** 美术参考提供表现办法，不能代替产品、市场或消费者证据。

| 项目条件 | 当前结论及其影响 |
| --- | --- |
| 商品与品牌 | 小度智能音箱随身版；便携蓝牙音箱。商品名称中的“智能”需配合实际手机/App使用条件说明 |
| 受众设定 | 希望在书桌及干燥轻出行情境听手机音乐的人；这是创意情境设定，消费者画像研究待补充 |
| 平台与用途 | 作品集概念套系，暂不绑定电商平台；具体上架平台、类目及最新规范待补充 |
| 价格与商业定位 | 当前有效售价、对照价及价格带待补充，不能据旧促销图推导性价比优势 |
| 已获审核 | 三张新VI概念的效果已通过；无需重新选方向 |
| 本轮工作 | 更新项目依据、因果关系、图组分工及缺口；未生成或改动图片，未将文档完成记作成图交付 |

最终范围沿用[项目大纲与最终交付清单](项目大纲与最终交付清单.md)：**R01–R03三张精修母版 → P01–P03三张干净产品展示 → H01–H03三张营销海报＋EC01–EC05五张电商主图 → D01–D08组成一份详情长页及切片**；另附作品集案例和可编辑源文件包。母版、复用输出和同一长页切片分别计数，不由此增加独立场景数量。

以下“购买理由”均为基于事实的设计推导，未被消费者调研或转化数据验证。当前不强行凑三个竞争优势。

## 4. STRATEGY：先确定卖点和每张图的任务

五类交付承担不同工作：**R固定产品身份 → P把产品看清 → H建立主题与吸引力 → EC回答购买疑问 → D把条件与细节讲完整。** 图片共享素材和视觉规则，但不以同一正面换标题来完成整套。

| 图／模块 | 用户要理解的问题 | 主信息与依据 | 画面／信息结构 | 与前后图的关系 |
| --- | --- | --- | --- | --- |
| R01–R03 → P01–P03 | 外形、顶部和背部到底是什么样？ | 真实照片及规格中可支持的外观/接口信息 | 分层精修母版导出透明素材；再做干净整体/顶部/背部展示 | 是各类图共享依据，不另编三个新角度 |
| H01 便携主视觉 | 这个产品与什么生活方式有关？ | 日常音乐，随手带走；约96g为辅助信息 | 承接已审01手持与包口，正式竖版1080×1440重排 | 提供主题印象和EC02/D02可复用的动作素材 |
| H02 居家生活 | 放在日常桌面是什么感受？ | 给日常，添一点音乐 | 承接已审02木桌、阅读、侧光，正式横版1920×800重排 | 表达氛围，提供EC04/D03/D06场景，不承担完整规格 |
| H03 手机音乐 | 手机、音箱和音乐有什么关系？ | 手机里的音乐，换个地方听 | 承接已审03淡蓝灰、手机与路径，正式方版1000×1000 | 以传播主张为主；EC03/D04另补使用信息 |
| EC01 商品识别 | 这是什么，怎样获得音频？ | 产品全名；便携蓝牙音箱，连接手机播放 | 完整产品为焦点，商品名→品类→产品 | 先解决身份与基础能力，再进入便携理由 |
| EC02 轻巧便携 | 带走方便吗？ | 约96g；资料标称值，以实物为准 | 手持/包口动作＋一项重量信息 | 把EC01的产品放进携带行为，不再重复品类大标题 |
| EC03 手机连接 | 手机音乐怎样通过它播放？ | 蓝牙连接，手机播放 | 手机→路径→音箱；普通播放与助手条件分组 | 补“怎么用”；助手条件详见D04 |
| EC04 播放时长 | 资料标称可以播放多久？ | 约10小时播放*；70%音量实验室条件及实际差异 | 居家情境、数字与同屏脚注；时间图形为辅助 | 增加时长依据，区别H02的情绪主题 |
| EC05 产品细节 | 产品表面与两个按键能看清吗？ | 外壳/网罩细节；麦克风键、电源键位置 | 顶部为主、外观局部为辅，短标签 | 用不同视角结束五图；完整配置移至D07 |
| D01 产品认知 | 是什么产品，主要用途是什么？ | 商品名、便携蓝牙品类和手机播放 | 可靠完整产品＋核心主张 | 先给认知框架，不等到页尾才交代手机依赖 |
| D02 轻巧便携 | 为什么适合随手带走？ | 约96g及标称说明 | 复用手持/包口，补真实尺度关系 | 承接认知、展开主卖点 |
| D03 播放时长 | 时长信息有什么条件？ | 约10小时与70%音量实验室条件 | 复用居家素材，完整呈现条件 | 展开支撑理由，不把条件隐藏在另一模块 |
| D04 手机连接 | 普通播放和助手各怎么用？ | 蓝牙配对手机；助手另需小度App打开及按键调用 | 两组说明，操作手势待补充 | 完成基础功能理解；不把App条件覆盖到普通蓝牙播放 |
