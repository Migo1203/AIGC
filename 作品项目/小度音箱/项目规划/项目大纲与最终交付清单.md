# 小度随身音箱｜项目大纲与最终交付清单

更新：2026-10-28。**本项目把“小度智能音箱随身版”的真实产品资料，转化为一套能解释购买理由、保持统一美术语言的国内电商概念视觉，并整理为求职作品集案例。** 项目为独立概念练习，非品牌委托；暂不绑定平台，不宣称为当季新品。深圳是求职目标城市，不是已经研究过的消费者地域。

## 先看项目在做什么

- **输入**：产品照片与商品资料、品牌历史设计依据、四组美术参考、用户已通过的三张新VI概念。
- **要解决的问题**：过去部分方图只替换标题，产品角度和版式重复；基础可读、参数无误，还不足以说明每张图为何存在，也不足以形成有差异的商业套系。
- **本轮做法**：先界定能说的商品事实，再把事实转成购买理由和图片任务；以已通过的美术方向统一全套，同时让各图承担不同的信息与构图职责。
- **最终结果**：产品精修、产品展示、营销海报、电商主图、详情页五类，另附案例与源文件包。数量、复用关系和完成标准见下文。
- **当前状态**：三张概念的效果已通过；策略与大纲已按本轮要求更新，旧图正式重做尚未开始。竞品、消费者评价及正式制作缺口写“待补充”，不把文档完成等同成图完成。

### 本轮依据与方法

按用户指定的 [ecommerce-visual-strategy v0.1.0](https://github.com/Migo1203/AI-Skills/blob/c9bec033d9ef528ceac10d13a242a53ffbfedae5/plugins/skill-lab/skills/ecommerce-visual-strategy/SKILL.md) 执行，固定提交 `c9bec033d9ef528ceac10d13a242a53ffbfedae5`；已读取该版Skill及其 `references/deliverables.md`、`references/prompt-patterns.md`。本轮应用方法，不修改Skill，不新生成图片。

证据分为**资料标称、已独立核实、可据参数合理推导、待确认/冲突**。实物照片可核对可见外观，不等于已实测重量、续航或音质；创意推导也不等于消费者研究结论。

**项目的因果链：**

> 商品资料明确“能说什么”＋竞品/评价研究明确“需要解释什么”（后者待补充） → STRATEGY把事实转成购买理由与图片任务 → DIRECTION统一表达气质 → DIFFERENCE让各图分别承担信息与视觉职责 → DESIGN落实每图文字、画面和依据 → PROMPT核对真实输入与执行方式 → 制作、审核并整理五类交付。

## 3. 制定商品图片策略：五步各解决什么

### 3.1 STRATEGY｜先确定卖点和图片任务

从“有什么参数”推进到“这对观看者有什么帮助、需要哪张图说明”。营销海报负责吸引与情境，电商主图负责购买疑问，详情页负责展开证据和条件。

| 事实 → 合理利益/疑问 | 图片任务与位置 | 为什么这样安排 |
| --- | --- | --- |
| 有具体外观和产品名称 → 先认清商品 | R/P提供母版和干净展示；EC01/D01建立认知 | 未认清商品前，情绪口号不能替代品类说明 |
| 约96g → 带走是否方便 | H01建立主张；EC02/D02用动作与标称重量解释 | 用真实尺度与动作把抽象便携具体化 |
| 手机蓝牙播放 → 音乐从哪里来、助手要什么条件 | H03吸引；EC03/D04解释播放关系 | 产品名称含“智能”，所以需区分普通播放和助手依赖 |
| 约10小时及测试条件 → 能听多久 | EC04/D03把数字和条件放一起 | 参数可用，但不能表现为无条件承诺 |
| 可见外观、双键、接口 → 细节与版本是否清楚 | EC05/D05看控制和材质，D07/D08补规格/选购 | 先展示已知结构，再处理需要核对的配置与套餐 |

便携、连接、播放时长的当前分工已可规划；由竞品和评价决定的卖点排序调整为**待补充**。完整逐图依据见[电商视觉策略](电商视觉策略.md)。

### 3.2 DIRECTION｜定义整套Art Direction

用户原话：“**三张图效果都不错，通过审核。现在整理项目大纲，先理清我最后要交付的东西**。”[三张新VI概念](../视觉概念/VI概念提案-2026-10-28/README.md)已通过，采用方向为**清爽亲和的生活数码**，主张“日常音乐，随手带走”。不重新要求选风格。

| 维度 | 已采用的方向 | 与任务的关系 |
| --- | --- | --- |
| 审美、光线、材质 | 自然侧光、暖白ABS与金属网罩、真实承托和生活触感 | 与小体积日常音乐产品相符；光线帮助分辨轮廓和材质，不凭材质推出音质 |
| 色彩与字体气质 | 暖白#F3F1EA、深灰绿#24352F、鼠尾草绿#91A58E、淡蓝灰#DCE8EC，少量杏色#D79D7C；清楚亲和的无衬线层级 | 灰绿组织主张和信息，淡蓝灰服务连接功能页；为项目目标色，不是官方VI或PNG实测值 |
| 空间、丰富度 | 便携/居家场景保留少量有效道具，功能页用路径和信息分组；不固定全套只剩空白背景 | 道具解释情境，图形解释关系，信息密度随任务变化 |
| 共同语言与可变部分 | 固定产品身份、色彩关系、字体系、弧线/连接图形原则；角度、构图、尺度、画幅与场景按职责变化 | 让系列可以识别，又避免同一正面换标题 |

品牌历史设计理念与参考取舍见[美术方向提案](../../../任务/商业视觉提案验证/小度随身音箱-美术方向提案-2026-10-28.md)。该理念只支持表达气质，不能转移其他型号的材质和功能。实际生成图字体无法由PNG确认；最终PS字库、字重、字号与完整样式表为**待补充**。

三张概念实际均为1254×1254 PNG，是已审效果参照；后续各画幅需要重排。正式制作按实物统一网罩、图案、双键和尺度，尤其校准03手机与音箱的相对比例；这是制作校准，不撤回概念通过记录。

### 3.5 PROMPT｜规划真实输入，准备好再交付执行

素材入口在[任务卡](主图与素材任务卡.md#素材入口与输入顺序)。已有基准B是工作候选；N03正面、N02/N08顶部、N04背部等实物照负责结构；已审01/02/03负责光色、构图及图形气质，不能替代结构真值。R01–R03最终母版仍为计划资产，不能写成已存在的完成稿。

进入某张正式制作前，应先完成“画面设计 → 实际附件与顺序 → 最终Prompt/PS步骤”的一致核对，再提交该制作方案供确认；不让用户确认一个缺输入的空壳。本轮是项目信息与大纲更新，**各正式成图的最终输入、最终Prompt、实际工具/模型及执行记录均为待补充**。已审三图的历史生成记录保留，不改写为正式版执行记录。

“GPT Image 2输入”沿用用户前次导图字段名称；历史image_gen调用未返回具体模型版本，不能据此声称实际用了GPT Image 2。纯PS可完成的修改写PS步骤，不为填字段强行安排生图；背景补图、产品编辑、构图参照的输入职责应分清。待补充项留在制作记录，不混入号称可直接运行的最终Prompt。
