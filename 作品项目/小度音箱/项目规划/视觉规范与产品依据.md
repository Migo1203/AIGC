## 2026-10-30 确定的电商设计方向

**方向：清爽亲和的生活数码。** 围绕“日常音乐，随手带走”，让人先认出小度智能音箱随身版，再理解它在居家和随行中的使用情境。品牌氛围关键词为轻巧、亲和、日常、连接、清楚；这些是本项目的视觉判断，并非小度官方 VI。

| 维度 | 统一方向 |
| --- | --- |
| 配色 | 暖白 `#F3F1EA` 用作背景基调，深灰绿 `#24352F` 用于标题和正文，鼠尾草绿 `#91A58E` 用于短线或小面积强调；淡蓝灰 `#DCE8EC` 用于连接类画面。产品保持已选素材的冷白色。 |
| 场景 | 以干燥的居家桌面、阅读角和轻出行情境为主，用浅木、书本、织物或少量绿植交代日常感；道具退居次要位置，避免遮挡产品。 |
| 构图 | 产品为主要视觉锚点，轮廓完整且有真实承托；主张与产品名形成清楚层级，文案和场景留有呼吸空间。同套页面共享对齐和留白规则，按任务变化角度与布局。 |
| 光影 | 以左上方柔和自然侧光为主，保留金属网罩质感、冷白机身边缘和接触阴影；背景可略暖，机身不染黄，不添加蓝色亮点。其他页面依据各自场景调整光向与投影。 |
| 字体 | 统一使用思源黑体 SC：主标题 Bold，产品名及说明文字 Regular；标题和正文使用深灰绿，次级说明应保持足够对比。 |
| 图形与氛围 | 简洁短线、弧线或必要的连接路径用作阅读引导；整体干净、自然、有生活温度，让数码产品清晰可信。 |

## 当前采用的美术方向

**清爽亲和的生活数码；主张“日常音乐，随手带走”。** [三张新VI概念](../视觉概念/VI概念提案-2026-10-28/README.md)已获用户“三张图效果都不错，通过审核”的确认，作为正式制作的视觉依据。三张原图均为1254×1254 PNG；概念效果通过不代表统一产品母版、分层PS文件或最终多画幅交付已经完成。

这套方向源于本产品的浅色圆润外形、资料标称轻巧便携及手机播放用途，并参考品牌历史设计理念与音频产品的商业摄影；依据和取舍见[美术方向提案](../../../任务/商业视觉提案验证/小度随身音箱-美术方向提案-2026-10-28.md)。历史品牌理念不是本型号的功能证明，四组音频美术参考也不是已完成的竞品或消费者调研。

| 美术选择 | 服务的任务与因果关系 | 正式制作时怎样检查 |
| --- | --- | --- |
| 自然侧光与浅暖空间 | 让日常听音乐的情境具体可感，也让浅色产品与真实承托面形成体积 | 外壳不过曝，网罩与外壳有材质差别；投影、反光和接触随场景重建 |
| 深灰绿无衬线与短标题 | 延续已审概念的亲和气质，以清楚层级区分主张、参数与条件 | 标题先读，相关条件紧随；缩小预览可读，不靠极细小脚注收纳信息 |
| 鼠尾草绿弧线、音乐与连接图形 | 用少量连续图形串起携带、音乐和手机播放关系 | 弧线引导阅读，不模拟测量声波、无线距离或未经核实的性能 |
| 淡蓝灰功能页 | 与暖色生活页形成节奏，在手机连接任务中给设备与路径留出清楚空间 | 延续相同字体系和产品身份；手机、音箱的尺度和前后空间符合真实参照 |
| 手持、阅读桌与手机关系三种情境 | 分别表达“带走”“日常陪伴”“手机播放”，避免同一正面换标题 | 图组的角度、主体尺度、动作与信息结构确有差别，每种差别都支持本图任务 |

## 外观与生成约束

- 产品形状与颜色以用户已选的正面、45°、侧面、顶部和背部图为视觉基准；实拍用于核对按键、接口等真实细节。既有海报仅作光色和构图参考。
- 本套固定浅色机身、正面左竖条与右朝左折角图案、顶部灰色控制区内两枚按键。按正面观察为左麦克风、右电源；看背面时左右会随视角反转，不能机械复制。
- 保留网罩弧面、接缝、已见接口位置和合理厚度。实拍未清晰展示的内部孔纹/接点不靠模型补造；R03若不能确认细节，先保留真实整体背部，不放大当精密接口特写。
- 按用户最新要求，不添加或保留蓝色亮点，也不创造灯效。未展示挂绳安装位置的视角不要求新增挂绳或扣位。
- 可变内容是背景、道具、取景、留白、光线氛围与信息版式；改变背景后检查投影与色温。参数、功能条件、产品结构与来源关系不随创意改变。
