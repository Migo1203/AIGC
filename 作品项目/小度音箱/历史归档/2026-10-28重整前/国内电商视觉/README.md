## 当前项目主线

把商品事实变为清楚的购买解释，再落实到不同用途的图片：**产品资料/研究缺口 → 卖点与图片任务 → 已审Art Direction → 图组差异 → 单图设计/真实输入/Prompt → 制作与交付。** 便携来自约96g等资料的设计推导，手机连接需要功能澄清，播放时长附条件，40mm放规格支持；竞品/消费者证据为待补充。

美术采用**清爽亲和的生活数码**，主题“日常音乐，随手带走”。[新VI概念01/02/03](../../../视觉概念/VI概念提案-2026-10-28/README.md)已获用户效果审核，不再重新选风格；正式制作按实物统一产品和尺度，按用途重排信息。项目色板、光线及图形规则见[视觉规范](../../../项目规划/视觉规范与产品依据.md)。
