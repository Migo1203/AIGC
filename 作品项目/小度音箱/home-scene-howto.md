# 当前一步：制作居家阅读无字底图

第一张窗边海报v03已归档。现在制作第二张“居家阅读”图，先完成没有标题文字的场景底图，再检查和排版。

## 1. 先看目标效果

[打开居家阅读参考样图](参考示范/Codex示范-音箱-居家阅读-无字-v03.png)。这是Codex此前生成的示范，现已保存到GitHub供查看；正式居家结果目录尚无用户上传图片。

画面目标：暖米色房间、浅木书桌、书本与铅笔，右侧放一台手掌大小的音箱，上方留出排版空间。参考样图的v03是示范的迭代编号，不要求你先做三轮。

## 2. 下载两张产品参照

1. [产品外观参照：窗边海报v03](制作结果/海报排版/用户上传-音箱-窗边海报-局部修正样图-v03.png)。
2. [结构参照：顶部按键实拍N02](../../素材/产品资料/音箱/图片/实物照片/音箱-顶部按键-N02.jpg)。

分别打开图片，点击GitHub图片页面右上角的下载图标保存原图。在GPT Image中把它们作为两张图片附件上传；文字链接不能代替图片附件。先上传产品外观图，再上传按键图。

## 3. 复制这段完整提示词

```text
图1是音箱的外观参照，只参考产品和暖色基调，忽略原海报文字与背景。图2是同一音箱的顶部按键实拍，只补充按键结构。

请制作一张居家阅读场景的无字底图，竖版2:3。浅木书桌、暖米色墙面，左侧柔和自然窗光，背景少量虚化绿植。书桌左侧放一本合拢的普通A5大小纸质书，露出纸页和简单书签，旁边放一支普通铅笔；音箱放在书本右侧，两者与镜头距离接近，落在同一桌面上。

保持音箱手掌大小，约占画面宽度20%–23%；它的宽度视觉上约为书本21厘米长边的五分之二，明显短于旁边的铅笔。不要把音箱前置放大。书本与音箱都清楚可见，透视和接触阴影自然。

保留参照音箱的浅色圆润外壳、细密金属圆孔网罩、左竖条和右侧左向折角两块深色图案、顶部灰色控制区及左麦克风右电源两个按键。正面朝镜头，顶部略可见，不增加屏幕、按钮、接口或配件。

整体温暖、自然、简洁，表达日常阅读与音乐陪伴。上方约三分之一保持干净墙面，为后续排版留空间。本次不生成标题、产品名、标语、价格或水印；不添加额外logo或品牌标识，产品原有正面图案照参考保留。书封和背景也不出现可读文字。环境保持干燥，只输出一张完整图片。
```

若音箱仍明显偏大，只把当前生成的居家图作为附件，再使用这段局部修改词；不需要机械重跑历史v02、v03：

```text
只缩小当前图中的音箱，使其宽度约占画面总宽20%–23%，与书本和铅笔形成合理的小体积关系。保持音箱的宽高比、外观、朝向与底部落点，书本、铅笔、背景和构图保持原样。用自然桌面补回原音箱露出的区域，重建接触阴影，清除旧轮廓和重影。继续保持无字画面。
```

## 4. 生成后先检查

- 音箱比书本明显小，不和铅笔一样长；这是视觉尺度检查，不从图中测量实际厘米数。
- 机身、正面两块深色图案与顶部双键仍是同一款产品。
- 产品落在桌面上，没有漂浮、旧轮廓或重复阴影。
- 画面无文字，上方有放标题的位置。

把生成结果先发到对话里，我会检查是否合格。这个阶段先检查底图，之后才加入“给日常，添一点音乐”等文字。
