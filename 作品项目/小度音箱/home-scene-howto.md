## 2. 在选中的底图上排版

本图面向音箱概念项目的年轻居家用户，用书桌阅读场景表达“日常音乐陪伴”。它是竖版概念海报，不作为已适配某平台的主图。推荐沿用第一张的暖色底图、深绿色主标题和产品名层级。

文案只用三组：

- 产品名：小度智能音箱随身版
- 主标题：给日常，／添一点音乐
- 底部说明：独立概念视觉，非品牌委托。

以下为基于现有v03的起始建议，未作为像素测量结果；按字体和成图可读性调整。坐标原点为画布左上，X向右、Y向下，边界框为X/Y/W/H，字号单位为px。

| 元素 | 起始参数 |
| --- | --- |
| 画布 | 保持1024×1536、竖版2:3，不裁切、不放大音箱 |
| 对齐 | 三组文字居中对齐，中心线X=512 |
| 产品名 | X=192、Y=150、W=640、H=48；思源黑体或Noto Sans CJK SC，28px、中等字重，#393A33 |
| 主标题 | X=192、Y=300、W=640、H=240；分两行，84px、粗体，行距110px，#29401C |
| 底部说明 | X=112、Y=1400、W=800、H=48；24px、常规字重，#5A5145 |

产品名与主标题组成一组，底部说明独立；主标题最醒目，不添加价格、未经核实的性能卖点或装饰。保持书本、铅笔、音箱、背景与光影原样。

若你用常用设计软件排版，下载选中原图，分别新建三个文字图层即可；若继续用GPT Image，在下一节使用加字编辑词。两种方式都从已有底图继续。

## 3. 用GPT Image加字时的编辑词

将[现有v03](参考示范/Codex示范-音箱-居家阅读-无字-v03.png)下载为原图，作为图片附件提供给编辑工具。这里是提供编辑输入，不是重新上传GitHub，也不需要再次准备两张产品参照。

```text
请以附件中的现成居家阅读图为底图进行文字排版，只添加下列三组中文，不要重新生成场景。

保持1024×1536竖版2:3画布，保留原图的音箱、书本、铅笔、窗户、绿植、背景、颜色、光线和阴影；不移动、不放大、不重新设计产品，不裁切画面。

1. 产品名“小度智能音箱随身版”：放在上方中央，中心线X=512，文字区域约X=192/Y=150/W=640/H=48，28px左右、中等字重，深灰色#393A33。
2. 主标题分为两行，第一行“给日常，”，第二行“添一点音乐”：居中放在上方干净墙面，文字区域约X=192/Y=300/W=640/H=240，84px左右、粗体，行距约110px，深绿色#29401C。标题清晰醒目，不能遮住产品与道具。
3. 底部说明“独立概念视觉，非品牌委托。”：放在底部中央，区域约X=112/Y=1400/W=800/H=48，24px左右、常规字重，深灰褐色#5A5145。

使用清晰的中文无衬线字体。上述坐标与字号为起始排版建议，可为准确呈现文字做轻微光学调整。确保文字逐字正确，不添加其他文字、促销信息、logo或水印。只输出一张完整的排版图片。
```

## 4. 检查新排版结果

1. 三组文字逐字正确，主标题先被看到，产品名和说明有清楚的次级关系；缩小预览仍能阅读。
2. 对比底图，音箱结构、大小和位置，以及书本、铅笔、背景、光影均保留；文字不遮挡产品。
3. 标题、产品名与说明对齐，色彩与首张海报形成系列，无新增价格或未核实卖点。

产生新排版结果后再检查。已有v03底图的通过记录继续有效，不要求用户机械重复生成和底图审核；如实际编辑改变了产品或场景，再针对变化复核。

### 3. 复制这段完整提示词

```text
图1是音箱的外观参照，只参考产品和暖色基调，忽略原海报文字与背景。图2是同一音箱的顶部按键实拍，只补充按键结构。

请制作一张居家阅读场景的无字底图，竖版2:3。浅木书桌、暖米色墙面，左侧柔和自然窗光，背景少量虚化绿植。书桌左侧放一本合拢的普通A5大小纸质书，露出纸页和简单书签，旁边放一支普通铅笔；音箱放在书本右侧，两者与镜头距离接近，落在同一桌面上。

保持音箱手掌大小，约占画面宽度20%–23%；它的宽度视觉上约为书本21厘米长边的五分之二，明显短于旁边的铅笔。不要把音箱前置放大。书本与音箱都清楚可见，透视和接触阴影自然。

保留参照音箱的浅色圆润外壳、细密金属圆孔网罩、左竖条和右侧左向折角两块深色图案、顶部灰色控制区及左麦克风右电源两个按键。正面朝镜头，顶部略可见，不增加屏幕、按钮、接口或配件。

整体温暖、自然、简洁，表达日常阅读与音乐陪伴。上方约三分之一保持干净墙面，为后续排版留空间。本次不生成标题、产品名、标语、价格或水印；不添加额外logo或品牌标识，产品原有正面图案照参考保留。书封和背景也不出现可读文字。环境保持干燥，只输出一张完整图片。
```

重做时若音箱明显偏大，可只用新生成的居家图作为附件，使用以下局部修改词：

```text
只缩小当前图中的音箱，使其宽度约占画面总宽20%–23%，与书本和铅笔形成合理的小体积关系。保持音箱的宽高比、外观、朝向与底部落点，书本、铅笔、背景和构图保持原样。用自然桌面补回原音箱露出的区域，重建接触阴影，清除旧轮廓和重影。继续保持无字画面。
```

重做得到新底图时，才检查产品一致性、尺度、阴影和排版留白，并按来源命名与归档。重新生成不是默认学习作业，也不要求重复历史三轮迭代。
