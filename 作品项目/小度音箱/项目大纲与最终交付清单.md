**5张核心成图＋2张营销适配＋1份完整详情页＋1份作品集案例（含视觉规范）＋1套可编辑源文件与素材包。**

| 交付项 | 数量与内容 | 输出与完成标准 |
| --- | --- | --- |
| 核心商业视觉／商品展示组 | 5张，职责见下表；本身就是本项目的方形商品图组 | 统一输出1000×1000 PNG/JPG，保留清晰原始素材与分层工作稿；产品身份、光影、字体、图形及信息层级统一，各图有不同职责 |
| 营销尺寸适配 | 2张：便携竖版、居家横版，从核心视觉延展 | 1080×1440、1920×800；按新画幅重排文字与图像，不拉伸原图，不额外策划两个新概念 |
| 电商概念详情页 | 1份连续长页，按8个内容模块组织，附模块切片 | 750px宽；总高随内容和可读性确定，输出长页及8份切片，保留分层画板；复用核心图及产品素材，不额外生成8张场景 |
| 作品集案例 | 1份完整PDF及可继续编辑的案例文稿，视觉规范放入其中 | 包括任务、产品/品牌分析、参考取舍、视觉规范、代表迭代、最终应用、实际分工和复盘；按有效内容安排篇幅，不凑页数 |
| 源文件与素材包 | 1套，覆盖以上实际交付 | PSD/PSB及实际使用的原创矢量图形、产品/背景素材、字体与来源清单、实际生成和修改记录；只打包真正采用的内容，栅格预览不能代替分层源文件 |

计数规则：三张已审概念是制作依据，不再额外计为三张新最终成图。五张核心图也不另加一套五张商品图；长页和八张切片是同一份详情的两种输出；视觉规范作为案例章节及可复用样式资料，不重复制作一本完整品牌VI手册。

这里的尺寸是项目交付规格，不是已核实的平台上架规范。母版清晰度依据真实素材确定，不能仅靠放大画布宣称增加细节。

KV01兼商品识别与便携，不再把同一正面产品分别配两个标题凑两张。KV05负责细节识别；40mm是有来源的配置，不另设成“音质优势”核心卖点。

## 3. 详情页的八个内容模块

| 模块 | 回答什么 | 复用与补充 |
| --- | --- | --- |
| D01 产品首屏 | 这是什么、适合怎样的听音日常 | KV01与产品名、便携蓝牙品类表达 |
| D02 轻巧便携 | 为什么容易随行 | KV01手持/携带关系与约96g；保留标称说明 |
| D03 外观与触感 | 产品表面和形态有什么特点 | KV05与可靠外观近景；区分浅色ABS与金属透音网 |
| D04 播放时长 | 资料标称能播放多久 | KV04与约10小时、70%音量实验室条件及实际差异 |
| D05 日常场景 | 居家与干燥轻出行怎样使用 | KV02及已核对的便携画面，形成生活节奏 |
| D06 连接与控制 | 怎样连接手机，助手有什么条件 | KV03与顶部双键素材；普通蓝牙播放、助手手机App依赖分别说明 |
| D07 规格与接口 | 已知配置、尺寸与接口是什么 | 背部实拍与清楚参数表；约80×57mm、约96g、3W、40mm、Type-C等按原资料填写 |
| D08 选购确认 | 外观版本、配件与使用条件要核对什么 | 精简清单；按具体SKU核对配件，明确干燥使用，不编价格、赠品或售后承诺 |

这是原八模块规划的更新：原D03独立发声配置降为D07的规格支持，D03改为产品外观与触感。八个模块共享同一套素材与字体系，不是八张互不相干的海报。

## 4. 视觉规范与作品集案例包含什么

视觉规范作为本项目的产品视觉系统，记录：

- 采用的色板及主次关系、实际可用字体与字重、标题/说明/条件的层级。
- 产品比例、外壳/网罩/按键表现与光线规则。
- 灰绿弧线、音乐/连接图形、编号及不同画幅的版式规则。
- 真实品牌标识的使用边界与独立概念身份；不重新设计小度Logo或扩展为全品牌VI。

作品集案例按“任务与目标 → 产品和品牌依据 → 参考取舍 → 视觉方案 → 代表迭代 → 最终套系与应用 → 实际分工与复盘”组织。将旧稿、概念图与正式稿的改动理由连起来，只保留有解释价值的对比；不把全部历史文件都塞进展示页。

## 7. 执行顺序与项目完成标准

1. **统一产品素材**：准备R01/R02/R03，明确实际字库、可编辑文字与素材来源；解决会影响全套的产品一致性。
2. **先完成两张正式代表图**：KV01便携与KV03连接，验证生活摄影和功能图形能共享已审风格；保留已认可的美术效果。
3. **补齐其余三张**：KV02居家、KV04时长、KV05细节，检查套系节奏与各图职责。
4. **组装详情与适配**：复用稳定的核心图和母版完成八模块长页，再做C01/C02横竖排版。
5. **完成案例与源文件交付**：整理有效的前后对比、视觉规范、成品展示和复盘，检查PSD/PSB、导出与链接。

当五张核心图、两张适配、详情页、案例与源文件包全部实际存在，产品和文字检查完成，用户完成最终套系审核后，本轮静态项目才记为交付完成。三张概念审核通过是本项目的有效进展，未代替后续实际交付。
