用于保存用户提交的居家海报新排版结果和修改版本。现有[Codex居家v03底图](../../参考示范/Codex示范-音箱-居家阅读-无字-v03.png)已通过本轮底图检查，可以直接选用；用户已选v03，[Codex排版示范v01](../../参考示范/Codex示范-音箱-居家阅读-排版-v01.png)已生成并完成文字与主要构图检查，本目录仍暂无用户上传的新排版文件。
