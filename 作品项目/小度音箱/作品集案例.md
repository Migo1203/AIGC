# 小度随身音箱｜轻巧随行，音乐相伴

作品集案例初稿，2026-10-25。第三张PNG和三图系列复核已通过本轮检查，首轮一张主视觉、两张使用场景海报已齐。已补充Migo的个人复盘，并归纳[产品视觉制作SOP v0.1](../../资料库/学习资料/AIGC产品视觉制作SOP.md)，待后续任务验证复用效果；本页尚未作为网站发布。

## 1. 项目简介

以现有的小度智能音箱随身版为对象，制作一组国内品牌电商方向的独立概念视觉。围绕“轻巧随行、日常音乐陪伴”，将产品展示延展到居家阅读和户外野餐两种情境，练习在不同环境中保持产品识别、光影关系与文字层级。

本项目用于Migo的AIGC设计求职作品集，为自发概念项目，非品牌委托或官方宣传。画面统一为1024×1536、竖版2:3，尚未按某一电商平台的主图规范适配，也未进行商业投放。

## 2. 创意受众与信息选择

自拟受众为希望在居家与短途出行时听音乐的学生和年轻职场人。这是本项目的创意设定，并非品牌官方用户画像或调研结论。

主信息聚焦“便携”和“陪伴”，以清楚的产品形象及生活场景建立联系。本轮不堆叠价格、续航等参数，不演示未核对的独立语音能力。产品资料注明无防水功能，因此户外画面选择干燥桌面，没有涉水情境。

产品事实与外观参考来自[已归档的用户提交资料](../../素材/产品资料/音箱/规格资料/source-index.md)。资料包含实物照片和商品宣传图，不将全部照片记为用户自拍。

## 4. 视觉思路

浅色机身与暖米色、浅木色环境建立柔和基调，少量低饱和绿色连接居家与户外场景。深绿色大标题作为主要文字焦点，产品名和概念项目说明保持次级，让一张图只承担一个主要信息。

系列中保留产品圆润轮廓、正面深色图案、网罩与顶部双键等主要识别点，再结合不同场景安排光线、道具和接触阴影。主视觉强调产品，延展图强化情境；居家图保留了用户明确选择的近景取景。

居家PS稿已核对到产品名、标题、说明的纯色像素分别为 `#393A33`、`#29401C`、`#5A5145`。这些是可验证的图片色值，不能据此反查PSD字体；当前实际字体名称、字号与字距尚未逐项记录。

## 5. 三个真实迭代节点

**产品细节校正。** 主视觉排版v02的网孔均匀性与顶部按键细节仍需处理。Codex使用图像编辑工具，以实物正面和顶部照片为参照，针对网罩、双键和正面图案进行局部修正。v03上传后按实际文件重新检查，成为主视觉的当前采用版。此环节是AI辅助修正，不记为用户已完成的人工精修。[查看过程](制作记录/refinement.md)

**区分产品尺度与画面取景。** 居家底图前两版中的音箱相对书本显大，经两轮尺度修正后，v03通过底图检查。Migo随后认为该远景中的产品在画面内显得偏小，在PS中整体放大裁切为近景，以突出产品。这里的“相对道具大小”与“占画面的大小”是两项判断：产品和道具同步变化，不因裁切而认定产品相对比例失真。此选择不要求重新生成底图。[查看底图过程](制作记录/home-scene.md)

**用实际结果验证文字避让。** 居家PS文字v01的底部说明与铅笔重叠，影响可读性。v02通过调整背景、道具与文字的相对位置解决了问题，保留原定近景和系列配色。最终按实际画面接受修改，没有机械要求用户执行此前“说明上移60px”的试排值。[查看v01与v02检查](制作记录/居家排版.md#用户ps文字排版v02复核)

## 6. 实际分工与首轮交付

| 参与与工具 | 本项目中可确认的工作 |
| --- | --- |
| Migo | 提出求职与作品集目标，提交产品参考资料和候选图，判断构图与色彩，在PS中将居家图调整为近景，完成居家及轻出行文字排版、导出与提交；参与梳理任务方式，提出建立可复用SOP的目标 |
| Photoshop | 以文字排版为主要用途，并用于居家图整体取景调整；用户已确认这些操作，尚未读取PSD以核实全部图层参数 |
| Codex | 资料整理、任务拆解、文案与版式建议、提示词建议、审稿与归档；早期主视觉排版及局部修正、居家底图与排版示范使用了Codex图像生成与编辑工具，用户选择采用了其中的素材 |
| GPT | 用户已确认轻出行无字底图由GPT生成；具体图像模型版本与实际提示词未提供，不根据建议词推断实际提交原文 |

首轮成果为三张竖版概念海报及可追溯的候选、提示词建议和修改记录。网站、视频与电商详情图属于后续范围。目前未进行商业投放，也未测量效率提升，案例以已完成作品与真实修改过程呈现。

## 7. 个人复盘与流程沉淀

以下根据Migo在2026-10-25的回复整理为第一人称，保留其实际体验：

> 这组三张海报中，我最满意野餐轻出行图，主要因为构图和色彩符合我的预期。制作时没有遇到特别难的技术问题；GPT生成的结果不够满意时，我会用PS继续调整。例如居家图的远景让产品显得偏小，我将整体画面改为近景，并主要在PS中完成文字排版。这次我投入较多时间梳理任务拆解、检查与归档方式，希望把单次作图整理成可复用的SOP。目前已积累首个项目的流程经验，下一步需要在新的任务中验证和修订。

本次学习重点是审美判断、PS后期和任务流程设计。由此归纳的[产品视觉制作SOP v0.1](../../资料库/学习资料/AIGC产品视觉制作SOP.md)包含阶段输入与输出、生成和PS调整的选择、任务卡、审稿与归档规则。它是首个项目的初稿，尚无跨产品复用或耗时统计结论。

**待补充的制作信息：** 轻出行底图已确认由GPT生成，具体图像模型版本与实际提示词尚未提供；如需展示具体字体规范，再从PSD记录字体名称、字号和字距。参考资料的来源沿用[原始记录](../../素材/产品资料/音箱/规格资料/source-index.md)。

**当前进度：** 用户复盘已收录，SOP v0.1已整理。下一项实际制作任务按SOP任务卡执行，记录需要返工的原因和实际调整，再据结果修订流程；本次不要求重做已通过的三张海报。

**下一步可选扩展：** 案例文案确认后，再根据实际投递方向选择一项延展，例如横版尺寸适配、引用可信参数的卖点图，或约5秒的单镜头视频练习。它们不是本轮已完成交付，也不要求同时开展。
