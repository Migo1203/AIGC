## 制作顺序

1. **产品基准图**：用实物正面与按键照片做参考，清理背景和使用痕迹，得到清晰、完整的白底或浅底产品图。
2. **核对外观**：检查轮廓、网孔、正面深色图案、两个按键及接缝，确认产品没有被改造成另一款。
3. **主视觉底图**：使用通过核对的基准图，生成第一张无字主视觉。第一轮可以对同一提示词做少量尝试，再选择最合适的一张。
4. **合成与排版**：修正产品和环境的光影、接触阴影，加入名称、主题文案与必要说明。
5. **两张场景延展**：沿用同一产品参照、色彩和光线基调，分别制作居家、轻出行场景。
6. **保留过程**：记录关键提示词、候选图、问题与修改原因，整理成作品集案例。

具体可复制的内容见[GPT Image制作提示词](prompts.md)。生成结果保存在[制作结果](制作结果/README.md)。

## 外观与功能约束

- 以新增实物照片的正面图案、灰色控制区、麦克风与电源两枚按键为参照。实际照片没有展示挂绳的角度，不要求工具补出挂绳。
- 保留小体积比例。蓝色亮点的状态含义尚未确认，不用它表示特定功能已开启。
- 产品无防水功能，场景选择干燥环境。
- 本轮核心文案围绕便携和音乐，不演示尚待核对的语音按压方式或独立语音能力。
- 若后续使用“约96g”或“约10小时”等数据，保留约数与相应来源、测试条件。
- 图片来源和公开使用权限按实际情况记录；案例标明自发概念项目及实际使用的AI工具。

完整参数与限制见[产品资料](../../素材/产品资料/音箱/规格资料/product-specs.md)。

## 每张图的检查重点

1. 产品：外形、正面图案和按钮与参照一致，边缘完整，网孔没有明显融化或异常重复。
2. 场景：产品大小合理，没有漂浮，阴影方向与环境相符。
3. 设计：主体清晰，色彩统一，预留了可以排版的空间。
4. 信息：文字可读，卖点与产品资料一致，产品名拼写正确。
5. 交付：保留原图、选中版本和实际修改记录。
