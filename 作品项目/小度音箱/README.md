# 小度智能音箱随身版｜商业视觉项目

把真实产品资料与已审美术方向，做成用于求职作品集的国内电商概念套系。主张为“日常音乐，随手带走”，采用清爽亲和的生活数码方向；项目为独立概念练习，暂不绑定平台。

## 当前任务

用户已上传并选用7张1254×1254主图、8张941×1672竖版海报和6张1448×1086横版海报，已按内容归档：[主图与上传原名对照](制作交付/主图/README.md) · [竖版海报与上传原名对照](制作交付/竖版海报/README.md) · [横版海报与上传原名对照](制作交付/横版海报/README.md)。各图为本次Codex生成、用户选用后上传的PNG；其余交付与产品细节、参数及源文件仍需按实际情况完成和核对。

此前的视觉概念记录中，01便携、02居家、03手机连接已通过概念效果审核，04播放时长v02、05外观双键接口待审核。04 v02按续航参考重做，用开书→休息→合书、三段光线与日程节点表现时间推进，保留“约10小时播放”和70%音量实验室条件。[查看概念与版本对照](视觉概念/README.md)。

正式五类交付尚未全部完成；概念效果通过不表示产品母版、可编辑源文件或整套交付已完成。竞品/评价研究、部分商品细节及正式单图参数继续标“待补充”。
