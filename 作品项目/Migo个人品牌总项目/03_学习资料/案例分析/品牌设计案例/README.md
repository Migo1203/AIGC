## 后续归档方式

- 按案例建立文件夹，按讲解主题保存中文 Markdown；同一主题的补充更新原文件，新的学习主题另开一篇。
- 每篇注明日期、来源链接、实际阅读或查看范围；区分官方明确内容、概念解释、AI 分析及对 Migo 的建议。
- 讲解基础概念与理由，保留重要限制、可迁移原则和学习问题，不只罗列品牌信息。
- 图片分析说明看过的页面、图号或位置；原图出处、字体、色值或效果未经核实就保留未知，不猜测补齐。
- 用户的反馈与理解按真实回答补充，不代写学习心得，不将案例学习当作品牌方案已确认。
- 完成后检查链接与变更范围，按授权提交推送并核对远端；未推送明确标注状态。
