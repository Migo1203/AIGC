# Phase 6｜品牌应用入口

状态：[待研究] 当前没有已制作或已发布的品牌应用。

工作框架：[内容传播系统](内容传播系统.md) · [商业应用系统](商业应用系统.md)。栏目、具体触点和商业服务范围均仍待讨论。

项目边界：本目录属于 Project A，记录品牌资产在小红书和作品集中的视觉适配；网站策略、信息架构、页面 UI、开发和部署由独立的 Project B 负责。网站接入已确认品牌资产的规则见[网站品牌接入规范](../../02_网站项目入口与品牌交接/网站品牌接入规范.md)。

## 用户指定触点

小红书头像、主页背景、内容封面和作品集中的品牌视觉适配。每项应根据实际使用时的平台界面、支持能力和最新尺寸核验，不提前假定某平台功能或规格保持不变。

## 设计与验证任务

1. [待讨论] 明确每个触点的目标、主要受众、内容信息和 Migo / Beedog 的露出程度。
2. 基于已选定的识别系统制作头像、主页背景方案、封面模板和作品集应用；必要时另做正式与轻松场景版本。
3. 检查小尺寸识别、文字可读性、不同内容复用、背景对比度和品牌主体层级。
4. 区分概念样机、用户审阅稿、已发布应用与真实效果；保留源文件与导出版本。

商业应用可作为后续研究范围，具体形式和使用条件 [待讨论]；不把示意稿写成已合作、已投放或已产生商业成效。
