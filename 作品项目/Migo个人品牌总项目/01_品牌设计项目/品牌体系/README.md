## 如何调用现有设计研究库

完整研究留在 [design-resources 设计研究库](https://github.com/Migo1203/design-resources/tree/main/设计研究库)及各自项目；这里记录如何用，不复制案例结论、截图或素材。

| 用途 | 优先来源 | 转化成什么 |
| --- | --- | --- |
| 品牌视觉决策 | [视觉参考](../02_研究参考/视觉参考.md)、[品牌案例研究](../02_研究参考/品牌案例研究.md) | 从相同载体比较层级、留白、识别与强调方式；提取检验问题，不预设配色和字体。 |
| 设计方法学习 | [设计师方法研究引用](../02_研究参考/五位设计师方法研究引用.md) | 把方法转成可重做的步骤：写清变量、比较方案、记录取舍和适用范围。 |
| 品牌案例研究 | [品牌设计案例索引](../../03_学习资料/案例分析/品牌设计案例/README.md)、[案例研究模板](../02_研究参考/案例研究模板.md) | 区分原始事实、观察与推断，再说明哪条原则适合 Migo，哪条不适用。 |
| Beedog 角色开发 | [角色设计研究](../02_研究参考/角色设计研究.md)、[角色档案](../04_角色设计/README.md) | 比较轮廓、动作、叙事职责与使用边界；不继承参考造型、旧稿或世界观为正式设定。 |
| 个人网站与数字体验 | [Sommerseth 设计与案例分析](https://github.com/Migo1203/migo-portfolio/blob/main/UI设计/案例拆解/Sommerseth%20Design首页分析/设计元素与案例分析.md)、[网站品牌交接](../../02_网站项目入口与品牌交接/README.md) | 用参考检验导航、作品浏览和转场是否帮助理解；沿用自己的作品、内容与 VI 边界。 |

**研究使用流程（建议）：** 写出当前设计问题 → 指向原始研究或截图位置 → 提出一条可迁移原则和一个反例 → 在 Migo 的实际载体上验证。第三方素材只作研究；资产使用权限另核，不因归档而获得授权。

**维护：** 变更核心口径前先征得 Migo 确认；更新对应正文和决策记录。旧专题留作参考，八大模块继续作为执行索引，不再重复维护战略定稿。
