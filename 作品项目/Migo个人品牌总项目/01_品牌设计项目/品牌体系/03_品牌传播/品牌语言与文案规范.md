# 品牌语言与文案规范

**用途｜** 统一 Migo 的名称、主张、标语及中英文文案的层级；协助官网和内容编辑。英语段落需按真实用法审阅，不因已有英文句子就默认全套翻译定稿。

## 已确定的核心写法

- 主品牌写作 **Migo**，不是擅自替换为其他名字。Logo 字符形式另待设计。
- 品牌主张：**用设计的眼光观察世界，用创造的方式表达想法。**
- 品牌标语：**Think Clearly. Create Differently.** 中文表达：**清晰思考，创造不同。**
- 不把主张和标语混作同一句，也不要求每一触点都同时出现。
- 品牌内容不以“我做电商视觉”作为总开场；可以按具体案例说明电商视觉等实践。
- AI 是工作方法之一。若提及，说明它在此任务中的作用，并让人的观察、判断和实际工作可见。

## 文案操作规则｜建议

| 场景 | 做法 |
| --- | --- |
| 首屏 / 简介 | 先让读者知道 Migo 是谁，再用主张或身份说明说明内容入口；避免用标语承担全部身份介绍。 |
| 项目案例 | 写项目类型、背景、Migo 实际负责的部分和状态；概念练习显著注明。没有证据不写商业效果或客户背书。 |
| 过程记录 | 描述具体观察、备选和选择理由，不把每个改动包装成独特方法论。 |
| 中文 | 简体中文；句子清楚、直接、友善，术语首见解释。少用无证据的宏大形容词。 |
| English | 保持信息等值而非逐字硬译；专名与标语依已确认写法。未审的页面译文标为 draft。 |
| 署名 | 正文与作者名先使用 Migo。服务、角色或联合署名的固定格式待确认；依事实标出协作者。 |

旧「Stay curious. Design with care.」作为历史提案保留，**不再作为 V1.1 品牌标语**；新标语以本版为准。旧首页与关于页文字可作起草素材，但须按本版核对，不直接覆盖原文件。
