# 视觉参考管理

状态：已建立参考记录方法；本轮没有下载或实际逐张检查案例图片，因此没有宣称任何视觉观察或用户偏好。

## 优先参考入口

六个优先案例和原始链接见[品牌案例库](品牌案例研究.md)。其中 Slligy 与 Big Tea 的 Behance 项目页面本次返回 403，保留为候选并标记 [待验证]；Slligy 的同名 Dprofile 页面可读取标题，但尚未检查图片。

网络蜜蜂小狗表情包仅是用户提供的灵感线索，具体原始链接与出处 [待验证]。不得把未经确认的转载或相似图片写成原始来源。

## 每项参考的记录方式

| 字段 | 应记录的内容 |
| --- | --- |
| 参考名称与主体 | 品牌、项目、创作者；缺失即标 [待验证] |
| 原始链接与其他来源 | 页面、作品链接及访问日期 |
| 实际查看范围 | 哪个页面、哪张图、哪一帧，未看到的部分明确写出 |
| 可观察事实 | 只写实际看到或来源明确说明的内容 |
| 对本项目的研究价值 | 分析什么方法、结构或使用场景 |
| 与 Migo / Beedog 的差异 | 目标、受众、资源与品牌关系 |
| 状态 | 用户认可、候选、反例或未决定，不能替用户确认 |
| 素材使用条件 | 权利归属、是否可保存及是否可用于商业项目，未知时标 [待验证] |

## 素材存放

确有需要且使用条件允许时，将参考材料放入项目的 素材/参考资料，并记录来源；单纯研究时优先保存原始链接和文字笔记。不要把他人角色、商标或原照片作为 Beedog 可直接使用的素材。
