## 输入

使用前一阶段形成并经实际讨论的概念方向、[角色研究问题](../02_研究参考/角色设计研究.md)和用户反馈。保留“探索者 × 创造者”的人格基础，不将参考照片的具体造型直接搬入角色。

## 制作任务

1. 建立角色轮廓、比例和五官之间的内部关系，说明哪些特征是角色识别点。
2. 制作能够保持同一角色识别性的表情与动作，并检查情绪是否符合角色定位。
3. 建立正面、侧面、背面三视图，核对比例、结构与特征在不同角度的一致性。
4. 记录标准造型、允许变化的部分、避免误用的情况以及原创性对照依据。

## 预期产出与检查

标准形象、表情与动作组、三视图、角色设定和使用说明均需以实际制作成果为准。检查小尺寸与单色识别、不同角度的一致性，以及与具体参考的独立性；哪些版本采用需记录实际用户反馈。
