## 候选①｜Campbell Aero Classics 复古皮革飞行头盔

[官方型号与照片](https://campbellaeroclassics.com/helmets/)

![Campbell 官方型号页参考图片](https://campbellaeroclassics.com/__static/jdj5jdewjhvxmwvenutcthdka1vgsnqx/Vintage-pic-for-e-mail.jpg)

**来源事实：** 官方介绍包含 Classic、Warbird、Pacific、Vintage 等型号，并说明皮革外观之下使用 Kevlar／碳纤维壳体。不能把“皮革外观”直接等同于软帽。上图为型号页图片，不据文件名确认具体型号与配置。

**设计研究建议：** 研究拼接、包边、前额轮廓及独立护目镜的组合。可试深炭色帽体、蜂蜜色包边与蜂眼镜片，但配色和复古程度未获本人确认。大面积棕皮革可能强化传统飞行员联想，这是设计预测，待与 AC3 实际配合后判断。

## 候选③｜Gentex HGU-55/P 现代固定翼飞行头盔

[官方型号、多角度图片与说明](https://shop.gentexcorp.com/gentex-hgu-55-p-fixed-wing-helmet-system/)

![Gentex HGU-55/P 官方产品图](https://cdn11.bigcommerce.com/s-tdvizl1wrj/images/stencil/500x659/products/746/6642/HGU_55P_01__32653.1521641143.jpg?c=2)

**来源事实：** 官方将其描述为低轮廓设计，并提供不同镜片配置及可选呼吸装备整合。产品存在多个配置，不能把任何一张图片的细节当作全部版本的统一结构。

**设计研究建议：** 研究简洁壳体、镜片分层与固定关系，探索现代、利落的装备感。不要假定镜片都是侧铰链揭起，也不因使用军用装备参考就给 AC3 自动加入氧气面罩、武器或全身装甲。

## 两方向的共同约束

| 比较项 | 当前基础与待解决问题 |
| --- | --- |
| 角色本体 | 沿用当前 AC3 双足紧凑比例、犬类鼻嘴、双叶宽翼耳及毛色分区；本体也未正式定稿 |
| 面部 | 保留犬类鼻嘴与表情可读性，蜂眼结构可放在护目镜中 |
| 耳翼 | 需要留出耳根、拍动空间与活动路径；普通人类头盔不能原样套用 |
| 固定与抬镜 | 需核对固定带、耳根开口、镜片抬起路径；现阶段无结构验证 |
| 研究方法 | 若后续制作对照，应尽量固定本体、姿态、视角与画风，主要改变头部装备 |
| 风格与阶段 | 当前二维探索，机械化不作重点，不自动增加3D、动画或新生图 |
