# Project A｜Migo × Beedog Brand Identity

本项目负责 Migo 个人品牌策略、Beedog 原创角色、Logo、字体、色彩、辅助图形、品牌识别系统、品牌规范和设计源文件。Migo 是设计师与品牌主体，Beedog 是 Migo 的品牌角色；两者的具体关系见[品牌架构](01_品牌策略/品牌架构.md)。

## 八大模块入口

[查看个人品牌系统八大模块](品牌系统八大模块.md)：对照品牌策略、命名与语言、视觉识别、角色、辅助视觉、内容传播、商业应用及规范资产，查看已有资料、待补工作和当前状态。

## 与网站项目的边界

Project A 是品牌定义和设计源文件的来源；网站项目只将 A 已确认的相应资产作为正式品牌视觉使用。网站 UI、开发与部署由独立的 Project B 管理，见[网站项目资料入口](../02_作品集网站项目/README.md)及[总项目架构](../总项目架构.md)。
