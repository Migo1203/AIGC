Project A 是品牌定义和设计源文件的来源；网站项目只将 A 已确认的相应资产作为正式品牌视觉使用。网站 UI、开发与部署由独立的 Project B 管理，见[网站项目资料入口](../02_网站项目入口与品牌交接/README.md)及[总项目架构](../总项目架构.md)。
