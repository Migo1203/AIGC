## 2. 资产状态与记录

| 状态 | 含义 | 记录要求 |
| --- | --- | --- |
| 候选 / 草稿 | 正在探索，尚未由用户选择 | 保存来源、用途、版本与未决问题 |
| 已确认 | 用户明确选择了具体版本及适用范围 | 记录用户反馈、确认日期、源文件与许可 |
| 已替换 / 归档 | 被新版本取代或不再用于当前项目 | 保留历史与替换原因，避免误当现行版本 |

上传、导出或生成文件本身不等于用户确认。每项资产记录：名称、状态、版本 / 提交、源文件路径、导出格式、尺寸或画板、用途、来源、授权、确认依据和修改记录。

## 3. 文件与交接

- **源文件：** 保留可编辑版本，并将候选与确认版区分；不以预览图替代设计源文件。
- **导出：** 按真实需求提供 SVG、PNG、WebP、JSON / CSS 或 PDF 等格式；尺寸和数量依实际用途确定。
- **命名：** 普通文件和目录使用中文，README.md 与 AGENTS.md 按用户确认保留；版本、用途和日期可按项目需要写入文件名。
- **字体与素材：** 记录字体名称、版本、字重、语言覆盖，以及商用、网页嵌入和分发条件；不因可以下载就假设可以公开分发。
- **网站交接：** 只有经确认且适合网站的相应资产才交给 Project B；网站代码与品牌设计源文件分开管理。网站格式和接收记录见[品牌资产清单](../../品牌资产清单.md)。

## 4. 品牌手册验收

手册应对应实际已确认的设计，而非提前编造规则。完成时检查：主体和角色关系、标识与角色用法、色彩字体、辅助图形、应用示例、误用示例、来源与授权、文件版本和待解决事项。PDF 与最终源文件仅在实际完成并经用户选择后标记为已交付。
