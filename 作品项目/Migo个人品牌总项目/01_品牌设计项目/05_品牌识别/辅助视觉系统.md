# 辅助视觉系统｜研究与设计框架

状态：[待研究]。本文件定义需要研究和验证的范围，不包含已经选定的图形、配色、字体或角色形象。

## 1. 目标与边界

辅助视觉用于帮助 Migo 的品牌信息和作品展示保持一致，同时为 Beedog 留出合适的表达空间。Migo 是设计师主体，角色辅助品牌表达；辅助图形不能取代 Logo、角色标准形象或实际作品内容。

## 2. 候选元素

| 类别 | 需要探索的问题 | 当前状态 |
| --- | --- | --- |
| 基础形状与构图元素 | 哪些形状、分隔或容器能支持信息层级并延续品牌特征？ | [待研究] |
| 图案与纹理 | 如何在背景、封面或印刷物上形成重复，而不干扰阅读？ | [待研究] |
| 图标 | 哪些是品牌表达，哪些是网站或平台的功能图标？ | [待讨论] |
| 插画与角色扩展 | 插画是否与 Beedog 保持一致的造型语言，同时保有独立用途？ | [待研究] |
| 信息图与版式辅助 | 线条、标注、编号或信息块如何帮助说明真实的设计过程？ | [待研究] |

这些类别是研究清单，不代表所有类别都会采用。Beedog 的灵感来源不自动决定蜂巢图案、蜜蜂装饰或某种颜色；具体形态要基于策略、案例与原创概念另行探索。

## 3. 研究与设计顺序

1. 先阅读[案例研究](../02_研究参考/品牌案例研究.md)，实际查看参考图并记录来源、图号与观察范围。
2. 将品牌策略、视觉 DNA、角色概念和实际触点作为输入，提出有明确依据的候选方向。
3. 评估图形与 Migo 标识、Beedog 和作品图片同时出现时的层级，以及单独使用时是否清楚。
4. 在社交封面、作品集和商务资料等候选触点中验证；色彩、尺寸、比例和具体效果以实际方案为准。
5. 记录用户选择、未采用方向和原因，并将确认后的规则纳入品牌手册与资产记录。

## 4. 后续交付与验收

可能交付图形元素、使用规则、可编辑源文件、导出文件和误用示例；具体清单 [待讨论]。验收关注可读性、小尺寸识别、不同媒介的复用、与角色的协调和来源可追溯；不得直接复制案例的具体角色、标识或受保护素材。
