# Phase 4–5｜品牌识别入口

状态：[待研究] Logo、字体、色彩、辅助图形和 Migo × Beedog 组合规范均尚未设计或定稿。

辅助图形、图案、图标和插画的研究范围与验收问题见[辅助视觉系统](辅助视觉系统.md)；该文档目前是工作框架，不代表已选择具体视觉方案。

## 前置条件

基于已讨论的品牌策略、阶段性案例研究和角色方案推进。Migo 是设计师与品牌主体，Beedog 是角色；标识不必预设一定包含角色，关系与组合方式由实际方案研究决定。

## Phase 4：识别设计

- 研究品牌文字、标识符号、字体、配色和辅助图形的不同组合方式，并说明每个方案的设计依据。
- 在适合的载体上测试识别、可读性、缩放、单色及中英文使用；字体的语言覆盖和使用条件需具体核验。
- 对候选、用户选定和未采用方案分别记录，避免将研究稿写成最终规范。

## Phase 5：组合与系统

- 定义需要的主体标识、角色独立使用、共同出现及正式场景的层级与适用条件。
- 通过实际应用验证留白、尺寸、对比度、排列关系和可变元素；数值以最终设计测试为准，不预先杜撰。
- 汇总色彩、字体、图形、角色和标识的用法与误用示例，为后续触点设计提供依据。

各阶段的交付与验收以[路线图](../07_项目管理/品牌路线图.md)为准。
