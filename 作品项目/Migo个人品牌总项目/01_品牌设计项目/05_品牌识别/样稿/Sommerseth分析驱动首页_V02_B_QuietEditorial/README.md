## 本稿验证的方向

- 将首页表达为「安静的编辑式创意档案」，以清晰文字层级、克制留白和真实项目素材构成首屏。
- 首屏同时呈现已确认的品牌主张「用设计的眼光观察世界，用创造的方式表达想法」、标语 `Think Clearly. Create Differently.` 和 Migo 的身份说明，避免只靠英文标语解释品牌。
- 使用 Works、Thoughts、About、Contact 页面锚点；Thoughts 目前链接至已有研究记录，不虚构文章或成果。
- 保留“自发概念项目”的事实说明。NED 图片来自现有 V01 样稿素材；项目呈现不代表客户委托或商业交付。
- Beedog 暂未出现，避免在角色视觉尚未确认时使用临时形象。

## 视觉候选与边界

暖纸色、深墨色、蓝灰和字体组合均只是本轮网页原型变量，用于比较阅读节奏；**不代表 Migo 已确认最终品牌色、字体、Logo 或 VI 规范**。NED 图片继续保留项目自己的视觉语境，不强行换成 Migo 候选色。

样稿沿用 A 版目录中的 `ned-cover.jpg` 和 `ned-strategy.jpg`。图片保留原始 4:3 比例，避免在窄屏裁掉封面文字和项目说明。

## 交互与响应式

- 桌面导航与手机菜单入口指向对应首页章节；移动菜单可由按钮切换，并提供键盘关闭处理。
- 项目图片有轻微 Hover；首屏图片采用裁切显现，章节内容在进入视口后淡入。
- 支持 `prefers-reduced-motion`，并提供键盘焦点样式。
- 已针对 1440、1024、768、390、320 CSS 像素视口检查首屏显示与图片比例；截图用于静态视觉对照，不等同完整真实设备验收。
- Impeccable 静态检测仍会提示微型英文标签的可读性、暖纸色的常见化风险和斜体衬线标题的使用惯例。这些是设计审阅提示，不是自动判定；下一轮应结合本人审阅决定是否调整。

## 与 A 版的关系

B 版是新建的独立目录，不覆盖 `Sommerseth分析驱动首页_V01`。它是视觉方向对照，不继承或替换正式网站信息架构、部署设置和官网代码。可与 A 版使用同一批事实与素材比较气质、首页阅读节奏和图像表现。
