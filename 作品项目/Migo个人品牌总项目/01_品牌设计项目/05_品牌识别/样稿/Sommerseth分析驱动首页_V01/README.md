# Migo — Visual practice / 信息架构样稿 V02

本地单文件前端样稿，沿用 Sommerseth 分析驱动首页 V01 的视觉线索，在其基础上验证 Migo 网站导航规划 V02。**这仍是结构与浏览路径实验，不是官网，也不是 Migo 品牌视觉定稿。**

## 本稿呈现的全站结构

- **Home**：Hero → About → Recent Projects → 联系入口与页脚。
- **Projects**：完整项目档案入口；目前只列出一项 NED 自发概念项目，不把同一项目的不同章节重复算作多个项目。
- **NED Eric 案例页**：从精选作品或 Projects 进入；保留案例自己的暖色视觉语境，并提供返回项目档案与回首页 About 的入口。
- **Contact**：把招聘沟通与项目合作分开说明；联系方式尚未提供，因此明确标记“样稿、不能发送”，不伪造邮箱或成功提交状态。
- **异常路径**：未知 hash 显示 404 样式的恢复页，不加入主导航。

单 HTML 通过 hash 状态展示不同页面视图，支持前进／后退、移动端菜单、键盘跳过链接及减少动态效果偏好。它便于直接打开 `index.html` 检查，不代表最终上线就会采用单文件或 hash 路由。

## 视觉与素材边界

- 延续 V01 报告分析实验中的钴蓝 `#1458E4`、灰白底 `#F2F2F0`、深色文字、Geist 字体线索及圆角特征；不将这些写作品牌最终规范。
- Home 使用 Migo 作品集的中性框架；NED 案例页维持作品自身视觉，不强行统一成 Migo 品牌色。
- `assets/ned-cover.jpg` 和 `assets/ned-strategy.jpg` 来自本项目已有 NED 作品集 V04，仅作样稿预览。图片本身标明 NED 是自发概念项目及 AI 辅助设计；本稿不将其描述为客户委托或商业交付。
- Dembrandt 对 Sommerseth 单个首页的分析不含完整网站结构、文字、图片选择或页面转场。本样稿的架构来自 Migo 网站规划 V02，交互与文案是本轮样稿实现，不是对参考网站的事实复刻。
