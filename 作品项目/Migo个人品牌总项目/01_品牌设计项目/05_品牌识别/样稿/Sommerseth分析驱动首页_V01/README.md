# Sommerseth 分析驱动首页样稿 V01

用途：查看 Dembrandt 导出的 `DESIGN.md` 能为 Migo 个人作品集首页提供怎样的视觉起点。此为独立本地参考样稿，不覆盖官网，不代表 Migo 品牌视觉定稿。

## 本版根据的分析线索
- 主色：`#1458E4`
- 页面底色：`#F2F2F0`
- 正文深色：`#0E0E0E`，辅助灰：`#6E6E6E`
- 字体线索：Geist；本页优先使用本机已有 Geist/Inter，否则回退系统无衬线字体。没有复制参考站字体文件。
- 报告里识别到约 12px、28.8px 圆角，以及 1024px 断点。

## 不应被误解为分析结论的内容
Dembrandt 对单个首页抽取的 DESIGN.md 不含完整页面结构，也没有转场过程。因此首页布局、中文文案、图片选择和“缩略拼贴→项目页”的动效，均是本样稿的设计推演/试验，不是从参考站代码或报告复制得来。报告的间距值异常集中在 2–12px，本稿没有把它当作完整的大区块间距系统。

## 文件
- `index.html`：独立静态样稿；无依赖、无后端。
- `assets/ned-cover.jpg`、`assets/ned-strategy.jpg`：从本项目已有 NED 作品集 V04 复制的本地预览素材。

## 预览
直接用浏览器打开 `index.html`。点击首屏项目图、项目列表任一图，测试拼贴转场与项目预览；按 Esc 或点击 CLOSE 退出。页面适配桌面与手机，并响应系统减少动态效果设置。

断点说明：1024px 为参考报告中的提取值；本稿的响应式重排点为 900px 和 620px，是按实际内容另行设定的。
