# 素材目录说明

本轮没有生成角色图或 Logo，也没有下载第三方图片。以下子目录仅为后续实际素材预留；其中的 Git 占位文件用于保留目录，不代表已有设计成果。

| 目录 | 存放内容 | 记录要求 |
| --- | --- | --- |
| 参考资料 | 有必要且使用条件允许保存的外部参考 | 在研究文档记录原始链接、作者、查看范围和使用条件；不把参考作为可直接商用素材 |
| 草图 | 用户或项目后续产生的草图和概念探索 | 标注日期、方向、版本、来源和用户反馈 |
| 角色 | Beedog 角色源文件、表情、动作和视图 | 区分候选、修改版与用户确认版，并保留可编辑源文件 |
| 品牌识别 | 标识、字体、色彩及辅助图形源文件 | 记录字体与素材使用条件、版本和适用范围 |
| 导出文件 | 实际交付或预览的导出文件 | 标注对应源文件、用途、版本和预览 / 已确认状态 |

大尺寸或不可直接入库的素材，先记录位置和使用条件，再根据实际协作方式处理；不要覆盖已有版本，也不把概念稿称为已发布成果。

交付网站的品牌文件须先在[品牌资产清单](../../品牌资产清单.md)记录实际名称、格式、尺寸、确认状态、来源版本与使用条件。Project B 使用已确认的对应资产，不反向覆盖本目录中的设计源文件。
