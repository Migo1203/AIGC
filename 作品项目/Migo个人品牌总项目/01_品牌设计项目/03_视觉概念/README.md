# Phase 2｜视觉概念入口

状态：[待研究] 此目录目前只有探索计划，没有视觉 DNA 定稿、色板、字体方案或角色图。

## 进入条件

先完成品牌策略的必要讨论、六个优先案例的结构化研究和阶段性比较，并记录尚存的信息缺口。输入来自[品牌定位](../01_品牌策略/品牌定位.md)、[品牌架构](../01_品牌策略/品牌架构.md)和[品牌案例库](../02_研究参考/品牌案例研究.md)。

## 探索方向

- 从用户给出的“好奇探索、认真设计”和 Beedog 的角色性格出发，提炼可检验的视觉原则，而非直接确定最终形象。
- [建议，待讨论] 提出在造型逻辑、轮廓或视觉表达上有实质差别的多个方向；每个方向说明依据、适用场景和限制，不只更换颜色。
- 色彩、字体和角色轮廓均作为研究候选。保留来源、原创性思考、备选方案和用户反馈。

## 预期产出与检查

形成视觉 DNA、角色概念、色彩和字体探索记录；让用户能够比较不同方案的依据及取舍。检查小尺寸可读性、专业与亲和的平衡，以及 Migo 主体与角色之间的层级。哪些方向采用由后续实际反馈决定。
