# 视觉工作笔记｜探索简报 V01

**更新：2026-11-23｜状态：探索已启动，未定稿。** 本目录是当前新方向的工作区。它不是 AC3 的新版，也不替代既有品牌简报；[AC3 旧探索](../历史归档_AC3/README.md)单独暂存，不作为本方向的造型输入。

**提案原文：** [Migo 从零设计｜两轮提案](Migo从零设计_两轮提案原文.md)。保留独立构思与具体应用想法；当前执行范围仍以本简报为准。

## 共同需求与提案来源

- **共同需求：** 近期用作品集支持 AIGC／视觉岗位求职，长期建立 Migo 的创作辨识度。希望让人感到 Migo 有自己的想法、愿意探索，也会认真把想法落实。共用[品牌设计简报](../../01_品牌策略/品牌设计简报_讨论稿.md)，不重写既有定位。
- **提案来源：** Codex 基于上述需求独立提出「视觉工作笔记」作为品牌表达方式，另提出「观察点」作为可选角色。未沿用 AC3 的动物原型、耳翼、装备或世界观。
- **本人反馈与决定：** 觉得这个角度有启发，希望自己试着设计；要求另建并区分新旧文件，将 AC3 作为未完成角色暂时归档。这不是对字标、配色、符号、角色或命名的确认。

## 待验证的设计假设

| 层级 | 工作假设 | 不作为本轮前提 |
| --- | --- | --- |
| Migo 本人和作品 | 作品先被看见。案例用真实的「发现 → 判断 → 做成」组织内容；作品与实验笔记可分开阅读。 | 不要求改个人网站，不把作品集重构或模拟呈现写成已交付。 |
| 视觉识别 | 独立 Migo 字标；暖白、深墨为底，钴蓝作信号色候选；缺角取景框和圆点用作细节批注。 | 不预定字形、字号、色值或 Logo，不用品牌色覆盖项目原有视觉。 |
| 「观察点」角色 | 工作名。试一个略不对称的软框形体和一枚会移动的圆点；靠转向、停顿、回头表现「多看一眼」。无台词，也不靠服饰解释身份。 | 角色可单独放弃，取景符号可以独立保留。角色不负责解释设计，也不盖过项目内容。 |

## 第一轮：用 NED 的一个片段验证

1. 选一个完整画面和一个确实值得观察的细节，例如灯罩材质；用 Migo 的一两句话说明该细节为什么重要。
2. 先做「只展示作品」和「加入静态取景批注」的同版式草图。若静态批注有效，再试角色版本；素材、文字和核心排版保持一致。
3. 让没参与过项目的人复述 Migo 做什么、看到了哪处细节、记住了什么设计决定。若角色压过作品，或单看像加载图标，先改造型或暂只保留批注。AC3 不列入当前制作；如日后恢复，再单独决定是否作为对照。

**示范 V01：** [并排预览 PNG](NED取景批注_对照示范_V01.png) · [可编辑 SVG](NED取景批注_对照示范_V01.svg)。两版共用 NED V04 的完整灯体和灯罩材质特写；右稿只在灯罩亮面叠加钴蓝缺角框与圆点。说明是示范文案，不等于 Migo 已确认的项目复盘。

**读者反馈｜2026-11-23：** Migo 转述，看过这份示范的读者认为取景批注确实让人更容易找到细节。这是 NED 这一处的初步反馈，未记录人数或观看条件；尚不能判断蓝框是否抢第一眼、是否帮助理解设计取舍，也未验证其他项目。

**下一步建议：** 保留静态取景批注，在另一个项目片段试一次。分开展示有、无批注的两版，不提示「找蓝框」；问读者先看哪里、能否指出特写的位置。未制作新角色图、动画或网站样稿；新稿不放入 AC3 的日期文件夹。
