- **提案来源：** Codex 基于上述需求独立提出「视觉工作笔记」作为品牌表达方式，另提出「观察点」作为可选角色。未沿用 AC3 的动物原型、耳翼、装备或世界观。

## 第一轮：用 NED 的一个片段验证

1. 选一个完整画面和一个确实值得观察的细节，例如灯罩材质；用 Migo 的一两句话说明该细节为什么重要。
2. 先做「只展示作品」和「加入静态取景批注」的同版式草图。若静态批注有效，再试角色版本；素材、文字和核心排版保持一致。
3. 让没参与过项目的人复述 Migo 做什么、看到了哪处细节、记住了什么设计决定。若角色压过作品，或单看像加载图标，先改造型或暂只保留批注。AC3 不列入当前制作；如日后恢复，再单独决定是否作为对照。

**示范 V01：** [并排预览 PNG](NED取景批注_对照示范_V01.png) · [可编辑 SVG](NED取景批注_对照示范_V01.svg)。两版共用 NED V04 的完整灯体和灯罩材质特写；右稿只在灯罩亮面叠加钴蓝缺角框与圆点。说明是示范文案，不等于 Migo 已确认的项目复盘。

**读者反馈｜2026-11-23：** Migo 转述，看过这份示范的读者认为取景批注确实让人更容易找到细节。这是 NED 这一处的初步反馈，未记录人数或观看条件；尚不能判断蓝框是否抢第一眼、是否帮助理解设计取舍，也未验证其他项目。

## 角色动作试稿：观察点｜回头看

**试稿 V01：** [无字四格 PNG](观察点_回头看_黑白四格_V01.png) · [可编辑 SVG](观察点_回头看_黑白四格_V01.svg)。沿用同一张音箱图，各格产品位置与比例不变。按左上、右上、左下、右下阅读：路过 → 折返 → 凑近看双键 → 离开并留下静态缺角批注。角色与批注是可编辑矢量，产品照片灰度化后内嵌；未使用生图模型。

**待验证：** 先单独给没看过分镜的人看无字图，不提示角色设定。问「它做了什么？」再追问「为什么又回来了？它在看哪里？」若读者主要读成扫码或图标移动，先调整折返的姿态和第三格的停顿感，不急着加五官或做动画。

本轮仅完成静态动作试稿，未收集读者反馈，未制作动画或改动网站。角色未定稿，AC3 状态不变。
