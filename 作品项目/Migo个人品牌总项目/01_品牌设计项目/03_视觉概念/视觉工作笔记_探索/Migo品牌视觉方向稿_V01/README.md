## 设计设定

- 纸白 `#F4F2ED` 用作页面底色，墨黑 `#20211F` 用作正文，钴蓝 `#2148C5` 用作细节批注候选。项目图沿用各自原色。
- 以衬线字标作为初始展示，因为它延续了测试板里的作者署名。切换字标后，案例版式与正文保持一致。
- 排版以中文无衬线为主，短英文索引用于交代项目或细节。按开场、整体、局部和说明的顺序阅读。
- 图片取自 [NED 取景批注示范](../NED取景批注_对照示范_V01.svg)及[小度音箱取景批注示范](../小度音箱取景批注_对照示范_V01.svg)的内嵌项目素材。交付采用独立 HTML 审阅页。

## 执行与检查

1. 用原有素材完成三个应用画面及字标对照区，接通字标和批注色切换。
2. 在桌面与手机宽度检查图片完整性、文字层级和操作。记录渲染结果与可审阅预览。
3. 更新探索入口、品牌任务清单和共用进度图，将方向稿、说明和预览同步到 AIGC 仓库。

## 成稿与审阅

[交互样稿 HTML](index.html) · [电脑全页预览](桌面预览.jpg) · [手机全页预览](手机预览.jpg)

仓库内可直接浏览静态图片。本地打开 `index.html` 即可换色和切换字标，三个图像文件需与 HTML 放在同一目录。NED 细节旁的墨黑和钴蓝控件同时影响两个案例的缺角框。字标对照区的选择会同步更新页眉与页脚。初始组合为衬线字标和钴蓝批注，供对照审阅。两款字标均为系统字体的排版试样，换设备时字形会随可用字体变化。

使用 Chrome 检查了 1440、1024、820、768、390、320 像素宽度下的图像加载、横向边界、键盘操作、颜色与字标切换及锚点导航，并目视审阅桌面和手机截图。浏览器检查和用户审阅是两个阶段，目前等待 Migo 选择字标与批注色。
