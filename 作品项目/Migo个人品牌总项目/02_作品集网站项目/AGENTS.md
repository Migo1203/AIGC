# 网站项目协作约定

开始网站相关工作前，先阅读本目录 README、网站项目简报、网站地图、网站路线图、网站任务清单、网站决策日志、文档/网站品牌接入记录，以及任务涉及的现有资料；跨项目边界还须遵循上级目录的 AGENTS 和 总项目架构。

- Migo 是独立设计师与品牌主体；Beedog 是 Migo 的品牌角色，不是另一个设计师。品牌定义与已确认视觉资产以 Project A 为来源。
- 网站代码与 AIGC 品牌项目分开管理，目标仓库名为 migo-portfolio；本目录当前是 AIGC 中的网站规划与交接资料，不代表该独立仓库已经存在。
- 网站普通文档使用中文文件名；按用户确认保留 README.md 和 AGENTS.md 两个供工具识别的文件名。
- 未确认的 Logo、角色、色彩、字体和辅助图形保持 Pending / [待确认]；不可将临时占位内容写成正式品牌规范。
- 本阶段只做项目检查、文档和开发准备；用户验收前不进入 Wireframe 或 UI 设计，不生成最终网站、最终 Logo 或 Beedog。
- 用户明确授权将本阶段规划文档推送到本 Project B 文件夹；后续提交、推送、创建独立仓库或部署，按当次用户指示执行。
- 不修改 Project A 的品牌定义、设计源文件或资产；不把虚构作品、联系方式、效果或受众数据写成事实。保留中英文内容、来源与权限状态。
