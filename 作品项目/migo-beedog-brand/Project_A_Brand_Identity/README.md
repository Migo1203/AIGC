# Project A｜Migo × Beedog Brand Identity

本项目负责 Migo 个人品牌策略、Beedog 原创角色、Logo、字体、色彩、辅助图形、品牌识别系统、品牌规范和设计源文件。Migo 是设计师与品牌主体，Beedog 是 Migo 的品牌角色；两者的具体关系见[品牌架构](01_Strategy/Brand_Architecture.md)。

## 与网站项目的边界

Project A 是品牌定义和设计源文件的来源；网站项目只将 A 已确认的相应资产作为正式品牌视觉使用。网站 UI、开发与部署由独立的 Project B 管理，见[网站项目资料入口](../Project_B_Portfolio_Website/README.md)及[总项目架构](../PROJECT_ECOSYSTEM.md)。
