# 项目路线图｜Phase 0–7

更新日期：2026-11-08。阶段先后依据用户启动指令；时间、投入和具体人员分工 [待讨论]。每一阶段保留来源、实际产出与反馈，不将计划当作已完成成果。

## Phase 0｜项目初始化与资料整理

- **目标：** 在 AIGC 作品项目中建立独立、可持续维护的项目空间，固定已知品牌关系与工作边界。
- **任务：** 检查已有仓库；整理简报、定位、架构、任务与决策；建立研究模板和来源目录。
- **交付：** 项目 README、策略与研究起始文档、路线图、任务清单、决策日志和素材管理结构。
- **验收：** 用户给定的 Migo / Beedog 关系、灵感边界和本轮不生图要求准确；导航有效；待定项清晰；原项目未被覆盖。当前文档已建立，待用户审阅。
- **前置依赖：** 用户启动指令与可访问的 AIGC 仓库。

## Phase 1｜品牌案例研究与设计趋势分析

- **目标：** 理解成熟品牌如何组织角色、标识、字体、色彩、图形和真实应用，为个人品牌策略提供依据。
- **任务：** 按统一模板研究 Mailchimp、Duolingo、GitHub、Slligy、Discord、Big Tea；核验来源与项目性质；实际查看案例图；比较适用于独立设计师的做法；选择有日期和来源的趋势资料，区分趋势观察与建议。
- **交付：** 六个结构化案例、可追溯来源清单、跨案例比较、阶段性趋势观察与适用边界、对 Migo 的策略建议。
- **验收：** 每案覆盖模板的 11 项；缺失信息明确标注；视觉判断有实际查看范围和证据；建议说明理由与不适合照搬之处；区分趋势、事实和个人判断。
- **前置依赖：** Phase 0 项目简报与初始定位。Slligy、Big Tea 的候选页面和用户所指案例是否一致仍需核实。

## Phase 2｜Beedog 视觉 DNA 与角色概念

- **目标：** 把策略和研究转化为可比较的原创视觉探索方向。
- **任务：** 提炼形态、人格、色彩与文字的研究原则；提出差异明确的概念；对照参考来源，说明原创性思路和应用限制。
- **交付：** 视觉 DNA、角色概念、色彩与字体探索及其依据、用户反馈记录。
- **验收：** 方向之间有实质差异，能说明与品牌策略和角色人格的关系；用户能够比较取舍；未确认的方案仍标为候选。
- **前置依赖：** Phase 1 案例研究与策略结论，以及需要补充的用户选择。

## Phase 3｜Beedog 原创角色设计

- **目标：** 建立可识别、可表达、跨视角一致的原创角色。
- **任务：** 完善标准造型、轮廓比例、五官、表情、动作和正侧背三视图；检查不同尺寸与单色使用；记录创作和对照依据。
- **交付：** 角色标准形象、设定与规范、表情及动作组、三视图和可编辑源文件。
- **验收：** 角色形象与人格一致；不同角度和表情保持识别特征；可用于计划中的触点；有实际原创性对照和用户反馈记录。
- **前置依赖：** Phase 2 的概念探索结果和所需的方向选择。

## Phase 4｜Migo 品牌基础识别

- **目标：** 建立服务于设计师主体的标识、文字、色彩和辅助图形。
- **任务：** 探索 Logo、字体、色彩与图形系统；测试中英文、缩放、单色和不同背景；核查拟用字体的覆盖与使用条件。
- **交付：** 标识方案、字体和色彩系统、辅助图形及可编辑源文件。
- **验收：** 选择依据清楚；不同尺寸与常见背景可辨认；Migo 的主体身份明确；具体字体、色值和使用规则均有依据。
- **前置依赖：** Phase 1 策略研究、Phase 2 概念方向和 Phase 3 角色方案。

## Phase 5｜Migo × Beedog 组合与视觉系统

- **目标：** 明确设计师品牌与角色在不同场景的协作关系，形成一致、可扩展的视觉系统。
- **任务：** 确定品牌与角色的组合、独立使用、层级、留白、尺寸和允许变化范围；制作使用及误用示例。
- **交付：** Migo 与 Beedog 组合规范、识别元素清单、场景示例与源文件。
- **验收：** 正式、内容和角色互动场景中的责任与层级清楚；规则能在实际应用中复用；不会误把角色当作独立设计师。
- **前置依赖：** Phase 3 角色与 Phase 4 品牌基础识别。

## Phase 6｜小红书与作品集应用

- **项目边界：** 本阶段负责品牌视觉的触点适配和资产交付；作品集网站的信息架构、UI、开发和部署属于独立的 Project B。跨项目依赖见[总项目路线图](../../PROJECT_ROADMAP.md)。
- **目标：** 将视觉系统用于真实计划使用的内容触点。
- **任务：** 为小红书头像、主页背景、内容封面及作品集品牌视觉适配建立方案与模板；核验当时平台支持的功能与规格；测试信息层级和不同尺寸。
- **交付：** 各触点应用稿、可复用模板、预览与源文件；实际发布状态单独记录。
- **验收：** 符合所核验的平台条件；小尺寸可读；品牌和角色关系清晰；不同内容可复用；用户反馈与版本状态可追溯。
- **前置依赖：** Phase 5 组合规范，以及内容、账号和应用需求的必要信息。

## Phase 7｜品牌规范手册与项目复盘

- **目标：** 将经过实际使用和选择的成果整理成可维护的品牌规范与项目记录。
- **任务：** 汇总品牌策略、标识、字体、色彩、图形、角色、组合、应用、素材来源与使用条件；复盘决策、修改和未解决问题。
- **交付：** 品牌规范手册、最终源文件与导出清单、项目复盘及后续维护建议。
- **验收：** 手册中每条规则都能对应实际确定的设计或已记录的使用依据；文件、版本、来源和使用条件清楚；未完成事项如实列出。
- **前置依赖：** Phase 3–6 的实际成果与反馈记录。
