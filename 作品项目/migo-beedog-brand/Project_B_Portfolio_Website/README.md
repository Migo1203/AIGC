# Project B｜Migo Personal Portfolio Website

本文件夹集中存放网站项目的管理与品牌交接资料。网站项目负责策略、信息架构、Sitemap、Wireframe、UI、Astro / TypeScript / Tailwind CSS 开发、中英文内容、响应式、交互、SEO、性能、部署和维护。

## 独立仓库

网站代码应独立存放在用户指定的 migo-portfolio 仓库，不与 AIGC 合并为一个代码仓库。仓库所属账户、链接和可访问性仍为 **[待确认]**；当前 GitHub 连接未列出该仓库，对 Migo1203/migo-portfolio 的查询返回 404。本文件夹的存在不代表网站仓库、代码或部署已经建立。
