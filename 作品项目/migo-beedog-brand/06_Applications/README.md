## 用户指定触点

小红书头像、主页背景、内容封面和作品集应用。每项应根据实际使用时的平台界面、支持能力和最新尺寸核验，不提前假定某平台功能或规格保持不变。

## 设计与验证任务

1. [待讨论] 明确每个触点的目标、主要受众、内容信息和 Migo / Beedog 的露出程度。
2. 基于已选定的识别系统制作头像、主页背景方案、封面模板和作品集应用；必要时另做正式与轻松场景版本。
3. 检查小尺寸识别、文字可读性、不同内容复用、背景对比度和品牌主体层级。
4. 区分概念样机、用户审阅稿、已发布应用与真实效果；保留源文件与导出版本。

商业应用可作为后续研究范围，具体形式和使用条件 [待讨论]；不把示意稿写成已合作、已投放或已产生商业成效。
