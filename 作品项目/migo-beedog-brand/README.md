# Migo Personal Brand Ecosystem

Migo 个人品牌总项目的统一入口，包含独立管理的品牌设计与个人作品集网站两个子项目。项目以“好奇探索，认真设计”为核心主张。

**当前状态：** Phase 0 初始化文档已建立，待 Migo 审阅；Phase 1 案例研究已整理入口，尚未完成。更新日期：2026-11-08。

## Migo Personal Brand Ecosystem

总项目分为两个独立管理的子项目：

| 项目 | 职责与入口 |
| --- | --- |
| Project A｜Migo × Beedog Brand Identity | 品牌策略、原创角色、Logo、视觉识别和品牌源文件。[品牌项目文件夹](Project_A_Brand_Identity/README.md) · [品牌路线图](Project_A_Brand_Identity/07_Project_Management/Roadmap.md)。 |
| Project B｜Migo Personal Portfolio Website | 独立负责网站策略、信息架构、UI、Astro 开发、双语内容与部署维护。[网站项目资料文件夹](Project_B_Portfolio_Website/README.md)；独立仓库名为 migo-portfolio，**仓库链接：[待确认]**。 |

Project A 是品牌资产的来源；Project B 仅将 A 已确认的相应资产作为正式品牌视觉使用。两个文件夹用于分类管理资料，网站代码仍使用独立的 migo-portfolio 仓库，不与 AIGC 合并。实际位置与仓库可访问性说明见[总项目架构](PROJECT_ECOSYSTEM.md)。

## 首先记住

- **Migo 是独立设计师和个人品牌主体**，负责专业创作、设计决策与商业服务。
- **Beedog（蜜狗）是 Migo 的原创品牌角色**，负责品牌人格化、情绪表达与内容互动，不是另一个独立设计师。
- 专业方向：AI Visual Design / Commercial Visual Design。BD 暂不作为独立对外品牌。
- 角色灵感来自用户描述的网络蜜蜂小狗表情包，只提取感受与研究方向；不描摹、复制或商业化使用原照片。
- 先策略与研究，再探索视觉、角色与标识；本轮不绘制角色、不生成图片。

## 协作方式与状态

“已确定”表示用户已明确给出的要求；[待研究] 表示缺少资料或观察；[待讨论] 表示需要共同选择；[待验证] 表示已有假设或候选，但证据不足。建议不得写成用户已认可的决定。

每轮工作先读本页、项目简报、决策日志、任务清单和相关阶段资料；涉及网站或资产交付时，还需阅读总项目架构、资产清单及网站品牌接入规范。完成后同步记录来源、结论、用户反馈与下一步。各阶段只在具备前置输入后推进，不将计划或占位内容写成已完成成果。

后续阶段将按实际产出新增角色、标识、配色、字体和应用文件，不预先制造空的设计结论文档。素材子目录中的占位文件仅用于让 Git 保留目录。

2026-11-08 用户明确要求将初始化文件上传至 GitHub；上传不代表用户已完成对品牌方案的审阅。
