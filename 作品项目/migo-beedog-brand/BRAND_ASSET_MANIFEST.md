## 建议导出与交付检查

- **版本与状态：** 每次交付记录资产编号、实际文件名、格式、像素尺寸或矢量画板、版本 / 提交、确认状态、用途和使用限制。保留 Project A 的可编辑源文件，不以导出文件代替源文件。
- **SVG：** 检查可缩放画板、在目标浏览器中的显示、关联字体或外部资源是否可用；优化不应改变已确认的造型与比例。
- **PNG / WebP：** 按实际网站展示尺寸导出适当版本，记录像素尺寸、透明背景需求与颜色表现；具体尺寸和文件体积目标 [待确认]。
- **字体：** 记录字体名称、版本、字重、中文 / 英文覆盖，以及网页嵌入、分发、商用和授权证明；不假设字体文件可随仓库公开分发。
- **颜色变量：** 仅将 Project A 已确认的色值与含义写入最终 JSON 或 CSS；测试用途、对比度和前后台显示，未确定值不得冒充品牌色。
- **品牌规范 PDF：** 由实际完成并确认的规范导出，列明版本和适用范围；本轮不生成虚构手册。
