## 上传与命名

打开相应分类，点击 **Add file → Upload files**，上传后点击 **Commit changes**。新增文件使用能描述内容的名称，例如 `音箱-侧面-02.jpg`；后续实际修改版本可以加 `v02`、`v03`。

原007与008内容及SHA256完全相同，008副本已删除，保留[007](规格与说明/音箱-App与按键使用条件-007.jpg)；原008上传记录仍可在来源索引和重命名表追溯。各图的拍摄者、来源与公开使用权限沿用原资料记录，分类与改名不改变其来源。
