## 使用时需要保留的条件

- 小度助手采用按键说话方式，需要连接手机端小度App，不支持“小度小度”语音唤醒。
- 免提通话需要蓝牙连接手机。
- 资料明确提示无防水功能，建议在干燥环境使用。
- 约10小时续航为页面标称，图中注明70%音量的实验室条件，实际使用会有差异。
- 商品图提示新旧外观混发；本轮以新增实物照片的正面图案、双按键和机身结构为参照。
- 新增套餐图中的充电配件与原包装清单分别记录，具体随附内容以实际订单或包装核对。
