# 图片素材

这个目录用于存放网站共用图片，例如头像和后续确定的网站封面。

音箱实拍和规格放在[产品资料](../产品资料/音箱/README.md)。当前成品状态与入库规则见[制作交付](../../作品项目/小度音箱/制作交付/README.md)，旧海报和过程资料已集中到[历史归档](../../作品项目/小度音箱/历史归档/README.md)，不按旧居家指南继续上传。

## 上传图片

1. 在 GitHub 中打开 `素材/网站图片` 目录。
2. 点击 **Add file → Upload files**，选择需要上传的图片。
3. 点击 **Commit changes** 保存。

图片可以使用 JPG、PNG 或 WebP 格式。文件名建议使用英文字母、数字和短横线，例如 `project-01-cover.jpg`。
