# 电商视觉 Skill 调用复盘｜小度音箱项目

整理日期：2026-11-03。依据项目现有制作记录、Skill来源与验证记录，以及当前对话中可见的操作；不是对全部历史调用日志的完整审计。**未找到调用记录不等于能够证明从未使用。** 本文作为SOP试用依据，候选与优化项在下一项目验证；本次不修改或安装Skill。

## 一、先区分 Skill 与工具

- **Skill：** 让Codex按一套方法完成某类任务，例如分析商品、规划图组或审查排版。它不会自动保证画面、事实或商业效果正确。
- **工具或应用：** 实际完成读网页、生图、读写GitHub等操作。工具可以配合Skill使用，但“生成了一张图”不等于调用了一个电商Skill。
- **SOP：** 描述整个项目怎样推进、你和Codex怎样分工；Skill用于需要专业方法的具体环节。不是每一步都要调用新Skill。

## 四、实际使用过但不是电商 Skill 的能力

| 能力 | 本项目的用途 | 处理方式 |
| --- | --- | --- |
| 图像生成/编辑工具 | 生成或改图、调整海报与详情页候选 | 用户要求生图或改图时使用合适工具；保留产品结构，生成后的文字与细节再核对 |

| GitHub连接与Git | 查找素材、读取上传、命名和按要求推送 | 核对本地、远程、分支和版本；归档不自动等于已推送 |

## 五、值得补充的能力和优化方向

以下是针对项目中观察到的问题提出的建议，不把问题全部归因于“缺少Skill”，也不视为已经验证有效的更新。

| 优先级 | 问题与证据 | 建议怎样补充或优化 |
| --- | --- | --- |
| 高 | 排版初版出现69g与96g不一致；V02仍有接口类型及若干缺乏依据的文案 | 在现有策略和审稿流程中增加“事实表 → 跨图/长页数字、单位、条件和SKU逐项对照”的收尾步骤；不只依靠写提示词时提醒一次 |
| 高 | 早期图组出现画面相近、只换标题；基础排版通过不等于美术成熟 | 强化“卖点 → 画面关系”的可视化审查，检查动作、角度、尺度、光线和组图节奏；复杂美术提案可试用`art-direction`的部分方法 |
| 中 | 小度项目在制作续航图时，才发现需要新的同类案例 | 在SOP中固定两个触发点：前期整体参考研究；制作遇到具体卡点时定向补找。使用网页工具和资料库即可，暂不必为此创建独立Skill |
| 中 | 策略Skill v0.1.0基于当时用户自行生图、PS排版的分工；项目后期用户也明确要求Codex生图 | 优化使用说明：区分策略交付与实际生图工具，按用户当前指示路由；用户明确要求直接生成时，不让旧默认分工阻止任务 |
| 中 | `plan-ecommerce-visuals`与融合策略Skill覆盖重叠 | 为“整套策略”和“针对性审稿”写清选择条件；同一任务优先使用能覆盖目标的一个，不机械叠加和重复输出 |
| 后续验证 | 项目文档、候选图、本地归档和GitHub状态可能不同步 | 用项目入口记录来源、版本、审核状态和本地/远程位置；GitHub工具负责实际同步，不先创建专门Skill |

## 六、建议的调用时机

| SOP阶段或具体任务 | 建议使用 |
| --- | --- |
| 项目背景、产品事实、卖点、分图及文案 | 以`ecommerce-visual-strategy`为主；必要时读取其交付或提示词参考 |
| 查同类品、竞品或具体设计案例 | 先查已有资料库，再用网页搜索和读取工具；参考不等于已验证的竞品结论 |
| 美术方向不够具体、关键画面雷同 | 先用现有策略与真实参考形成可观看方案；如仍有缺口，试用`art-direction`中适合的Brief方法 |
| 生成底图、改图或局部清理 | 使用当前可用的图像工具；用户指示优先，Skill负责方法而不替代执行工具 |
| 具体排版、单图审稿或整套统一 | 使用`plan-ecommerce-visuals`，或在融合策略已覆盖时直接按其审稿方法检查 |
| 详情长图核对 | 查看实际长图，结合产品事实表、手机预览及平台当前官方要求；先按SOP执行，是否另建Skill待验证 |
| 作品集文稿与项目复盘 | 需要贴合用户写作风格时可用`write-like-me`；所有案例事实以实际记录为准 |
| 学习或创建、修改Skill | 分别按任务考虑`study-skill`或`skill-creator`，不纳入每次商品制作默认步骤 |

## 七、下一步怎么验证

下一个产品项目先用现有策略、视觉审稿与相应工具；如果在任务中出现明确且独立的缺口，再选择试用候选或提出新Skill。分工、可用工具及尚未验证的地方随项目标注并调整。记录任务、实际输入、输出、有效之处与问题；没有对照、实测或耗时数据时，不写成效率或商业效果提升。
