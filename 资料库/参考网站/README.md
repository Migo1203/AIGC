## 比较记录

浏览时可以先选出最喜欢的 2–3 个网站，再记录：

- 喜欢它的哪一部分：布局、字体、配色、交互，还是作品组织方式？
- 这种展示方式是否适合自己的图片和视频？
- 希望借鉴的 1–2 个具体细节是什么？
- 希望避开的设计或使用体验是什么？
