## 以后怎么放文件

- 产品照片与规格：放到产品资料相应分类。
- 新作品图片：先在对话中检查，通过后上传到对应作品分类；上传后由Codex整理名称和索引。
- 当前任务说明：使用现有操作指南，避免再创建多份重复步骤。
- 过去的检查与修改：追加到制作过程；实际提交的提示词原文保存到历史目录。
- 工具教程、文章和网站：放到资料库的相应分类。
