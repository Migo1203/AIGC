## 以后怎么命名和上传

- 本项目后续沿用以下约定：你上传图片并告知我后，我会同步仓库，按内容分类、统一命名，并更新图片索引和文档引用。
- 新样图先在对话中检查；检查合格后由你上传GitHub，再进行仓库归档。检查通过的范围会标明，例如“版式通过、产品细节待精修”。
- 每一步先说明当前任务目标、素材链接、可复制提示词、检查标准和上传位置。若提供Codex生成的示范，必须附用户可打开的图片链接，不仅引用工具中的预览。
- 先进入对应分类，再点击 **Add file → Upload files** 上传。
- 名称写明对象与内容，例如 `音箱-侧面-02.jpg`、`音箱-窗边主视觉-精修-v01.png`。
- 相同内容的实际修改版本使用 `v02`、`v03`；不同构图用内容区分。
- 全部旧路径、新路径与内容校验值已记录在[重命名对照表](image-rename-map.csv)。
- 新制作示范图的原路径记录本次工具输出位置，仓库中的文件以“现路径”为准。
- 整理时保留图片内容、尺寸与格式；新上传且改名的文件继续补充旧名与新名对照。未选中的候选图保留作过程记录，完成选图后在索引里标注用途。
