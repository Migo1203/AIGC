版本号按来源和内容分别管理。相同的v03可能分别指Codex精修示范和用户上传稿，必须结合来源前缀识别。窗边海报用户稿v02、v03的编号保持不变，后续窗边修改版从v04继续。居家无字底图沿用v03，用户PS文字排版已有v01、v02，如再实际修改从v03继续；底图版号不决定文字排版版号。轻出行无字底图已有v01，文字排版独立编号且已有v01；如以后确实修改文字稿，再从文字排版v02继续。

来源前缀和目录不限制图片是否可被采用；选图与最终采用状态在制作记录另外注明。已有合格文件可直接继续下一步，不因来源不同而要求重做或重传。

## 以后怎么命名和上传

- 新上传资料先比对文件内容；完全相同的文件保留一份，补充来源记录并复用已有文件。
- 本项目后续沿用以下约定：你上传图片并告知我后，我会同步仓库，按内容分类、统一命名，并更新图片索引和文档引用。
- 新样图可先在对话中检查，或上传GitHub后通知检查；收到后按实际结果归档。检查通过的范围会标明，例如“版式通过、产品细节待精修”。
- 每一步先说明当前任务目标、素材链接、可复制提示词、检查标准和上传位置。用户自行制作图片，Codex负责指导、审稿与文件整理，不再生成示范图；纯PS调整不强行安排生图提示词。
- 先进入对应分类，再点击 **Add file → Upload files** 上传。
- 作品图片名称写明来源、对象与内容，例如 `Codex示范-音箱-居家阅读-无字-v01.png`、`用户上传-音箱-窗边主视觉-精修-v01.png`；产品参考资料沿用原来源编号。
- 相同内容的实际修改版本使用 `v02`、`v03`；不同构图用内容区分。
- 全部旧路径、新路径与内容校验值已记录在[重命名对照表](image-rename-map.csv)。
- 历史示范图的原路径保留当时工具输出位置，仓库中的文件以“现路径”为准。
- 整理时保留图片内容、尺寸与格式；新上传且改名的文件继续补充旧名与新名对照。未选中的候选图保留作过程记录，完成选图后在索引里标注用途。
