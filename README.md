# Migo的AIGC作品集

我计划建立一个个人网站，展示自己创作的 AIGC 图片和视频。

主要目标是在深圳寻找 AIGC 设计相关工作，以作品集展示从设计需求、创作迭代到最终交付的能力。

## 协作方式

2026-10-25确立的日常分工如下；2026-10-28用户另行明确授权生成三张VI概念参考，按当次要求执行：

- Codex默认提供当前任务、操作步骤、可复制的提示词及必要的素材和上传链接；用户明确要求生成时按当次授权执行。
- 用户自行生成图片或在PS中排版，Codex负责检查结果、提出修改建议，并整理用户通知已上传的新文件。
- 能在已有合格图片或PSD上完成的修改直接继续，不要求重新生成；纯PS调整不强行安排生图提示词。
- 已有示范保留为历史资料，已有采用记录继续有效。每次明确当前一步及完成标准，完成后再推进下一项。
- 当前任务以[音箱项目首页](作品项目/小度音箱/README.md)为进度入口；其他指南保留各阶段方法和历史记录，避免在多份文档重复维护待办。
