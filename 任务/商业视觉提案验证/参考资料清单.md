## 本轮范围与待补充

- **本次比较条件**：先引用音箱已有Brief及“作品集概念套系、暂不绑定平台”的范围；只补方法试验缺少的限制。另选产品或品牌时才建立新的Brief。没有市场研究支持的受众判断记为假设。
- **参考与审核状态**：三张新VI概念的美术效果已通过；四组商业案例保留为美术参照，不把概念通过推定为用户逐项认可全部商业参考，也不把其当作竞品调研。借鉴关系按字体、构图、光影、材质与概念分别记录。
- **需要避开的参考**：有助于说明偏好的具体案例或元素；不必为了凑数量额外收集。
- **品牌依据**：若是真实品牌，提供可用的Logo、品牌规范和已有传播材料；若是自拟品牌，标明概念项目及哪些内容尚待设计。
- **制作限制**：当前能使用的产品素材、工具、字体和时间；图片或字体能否公开用于作品集，未知时记录未知，不把可访问等同可商用。
- **竞品与消费者证据**：竞品选取与对比表、完整商品页观察、消费者评价来源与样本量、采集时间、原文及分类频次均待补充。高频痛点、疑问、套装/尺寸误解、使用门槛和认可点如何影响图片任务，目前只能记录判断条件，不能写成已发现的研究结论；现阶段不新增搜索。

先复用源图对照中的可读材料，必要时再补作品链接或图片。无法访问的链接只作为线索，不能写成已经看图分析的结果；已有源图分析不等于已取得公开使用授权或验证转化表现。

## 单条参考记录

| 字段 | 填写内容 |
| --- | --- |
| 参考名称与作者/品牌 | 可识别的项目名；未知处不补造 |
| 来源链接与访问日期 | 原始项目页面优先；图片可读情况 |
| 图片位置或本地文件 | 本次实际查看的图片；只链接或保存必要资料 |
| 参考职责 | 用于概念、构图、摄影、字体、材质或其他哪一项 |
| 具体观察 | 可在图中指出的关系及其作用 |
| 适合借鉴什么 | 与本产品、受众和渠道的关系 |
| 不沿用什么 | 其他品牌资产、不适用产品特征或不符合任务的表现 |
| 用户反馈 | 认可/不认可/待看，并写具体理由 |
| 使用边界 | 仅内部研究、可公开引用的依据、待核实授权等 |
