创建：2026-10-27。状态：**首份产品美术方向提案已完成，等待用户评审；代表画面与修订试验尚未执行**。本目录维护方法验证与评审记录；音箱项目的当前状态、制作顺序和采用版本仍以[项目首页](../../作品项目/小度音箱/README.md#当前任务)为准。

## 要解决的问题

现有产品视觉流程已覆盖资料整理、提示词、PS排版和审稿，但尚未证明它能稳定提出有辨识度、具商业理由的创意概念与美术方案。音箱项目已完成[源图对照与方向重整](../../复盘记录/小度音箱/商业视觉复盘与方向重整.md)，其中已有源商品图分析、A/B方向和逐图画面点子，不需在这里重新从零策划。

本任务承接上述基线，检验怎样将文字方向落实为可观看、可比较、可评审的美术提案，并记录参考校准和方法的实际效果，再决定哪些经验值得写入自己的Skill。

2026-10-28已完成[小度随身音箱美术方向提案](小度随身音箱-美术方向提案-2026-10-28.md)：按产品事实和品牌历史设计理念推荐“清爽亲和的生活数码”，选看四组匹配参考，并给出色板、字体性格和两张构图线框。方向及参考待用户评审，尚无新代表成图或实际效果验证。历史A/B保留为比较基线，当前推荐不是用户已选方案；旧M04/M05模板仍暂停。项目问题集中到[复盘记录](../../复盘记录/小度音箱/问题与改进记录.md)，制作状态仍在音箱项目首页。

## 分工

- **AI**：读取真实资料与参考图片，区分证据、推导和创意假设；提出概念、美术方向、文案与必要提示词；根据实际提案与用户反馈解释取舍。
- **Migo**：确定目标和审美选择；自行制作或选择图片、完成PS合成排版；反馈哪些方向想做、哪些不合适以及具体原因。
- 提案可以用参考图缩略图、色板、字体样张和简易构图线框展示；按需要做成HTML或PDF。无需AI直接生成图片，也不必先制作完整成图才能比较概念。

## 推进方法与交付

1. **固定输入**：引用现有Brief、产品事实、方向重整和待确认项，仅补本次比较确需的信息。同一次方法比较使用相同输入，注明模型、使用的指导文件与日期。
2. **研究实际参考**：解释参考中的构图、摄影、字体、材质、图形与阅读顺序如何支持目标；区分可借鉴的设计机制与不能照搬的品牌资产。
3. **发展概念**：先从已知需求与产品差异提出洞察或待验证假设，再形成有实质区别的方向。比较的是创意机制和画面结构，不用固定数量或换配色凑方案。
4. **展示并推荐**：用[提案与评审模板](提案与评审模板.md)说明概念、视觉语言、参考依据、构图草案、套图延展与执行难点，给出推荐和取舍。只展开本轮需要的内容。
5. **记录评审和修订**：按实际画面与用户目标判断，保留采用或否决的理由；只修影响目标的问题，不机械重跑所有步骤。
6. **验证后固化**：总结哪种指导确实改善了提案，哪些问题仍依赖模型、参考或专业判断，再决定是否写入自己的技能。不把格式完整视为商业设计能力已被证明。

预计形成：一份明确Brief、实际参考分析、一份可比较的提案、采用/修改记录与简短复盘。背景或概念图提示词在选定方向且实际需要素材时再交付；进入制作后沿用[现有SOP](../../资料库/学习资料/AIGC产品视觉制作SOP.md)。

## 本次完成标准

- 参考图片真实可读，产品宣称可追溯；受众洞察、创意设定和未知数据明确区分。
- 概念在产品关系、视觉表达或画面结构上具有可说明的差别，能解释各自适合什么目标。
- 提案能让人看懂摄影、字体、色彩、构图和延展，推荐理由与执行取舍具体；只有“高级、干净”等形容词不算完成。
- 产品身份与事实得到保留；素材、字体和PS实现路径明确，未知授权或执行限制有记录。
- 用户能作出保留、修改或搁置的选择，并留下理由；未开展真实投放、计时或测试时，不写转化率、效率提升或平台通过结论。
