# 提案与评审模板

用于[商业视觉提案验证](README.md)。以下是启动后按实际任务填写的结构，本目录尚未完成可视化提案。音箱已有[文字方向提案与源图对照](../../作品项目/小度音箱/国内电商视觉/商业视觉复盘与方向重整.md)，应直接引用并推进，不在这里复制为第二套方向方案。只使用能帮助选择与执行的部分，不要求每个阶段重复所有表格。

## 本轮任务与依据

- **Brief**：产品/品牌、商业问题、受众、渠道、主信息、交付范围与限制。
- **证据与假设**：哪些来自产品资料、用户需求或实际参考；哪些是推导、创意设定或待验证洞察。
- **方法记录**：采用的Skill或普通提示词、版本、模型、日期与本轮比较范围。
- **参考分析**：链接实际查看的图片，说明哪些设计机制支持目标，避免凭未读图片或案例名编造结论。

## 每个创意方向

| 内容 | 需要说明什么 |
| --- | --- |
| 概念名称与一句话核心 | 想让受众记住什么，核心创意怎样与产品或品牌发生关系 |
| 商业与创意依据 | 为什么适合本次目标；未知市场判断明确记为假设 |
| 视觉表达机制 | 使用何种摄影、图形、隐喻、叙事或排版关系，不只给风格形容词 |
| 美术语言 | 产品摆位、视角、光线、背景与材质；字体性格、层级、色板和图形规则；每项说明理由 |
| 参考图说明 | 逐张指出借鉴的部分、调整方式及不沿用的元素 |
| 可观看的草案 | 真实参考缩略图、色板、可用字体样张、简易构图线框；标明参考、示意与实际成果 |
| 产品与品牌保真 | 必须保持的结构、比例、颜色、Logo、文案事实和配件边界 |
| 延展 | 如何形成不同职责的系列图或尺寸变化；品牌身份设计另开范围，不把海报直接当成完整VI |
| 执行路径与代价 | 可复用素材、需用户制作的背景、PS合成/排版方式、主要难点与未核实条件 |

若字体尚未确定，先说明所需性格和候选，不把示意字体写成已采用，也不推断许可。若尚无成图，位置与尺寸属于构图计划，不能冒充实际测量。

提案可按需要保存为HTML或PDF，使用真实参考和示意图即可；本任务不要求AI生成新图片。没有生成或排版的内容不得冒充最终效果图。

## 方向比较与推荐

| 比较项 | 记录方式 |
| --- | --- |
| 与目标的关系 | 能指出哪个产品差异、需求或假设被转成了画面 |
| 概念区分度 | 说明方向间的核心差别及各自适合的目标 |
| 视觉说服力 | 对照实际草案解释构图、摄影、字体和色彩是否支持概念 |
| 可实现性 | 素材、工具、字体、PS工作量和产品真实性是否支持执行 |
| 推荐与取舍 | 推荐哪个、为什么；什么条件下改选另一个，哪些问题仍需解决 |

不以没有锚点的分数替代诊断，不把平台审核或转化效果作为未经测试的保证。

## 用户评审与修订记录

| 日期/提案版本 | 对应方向与位置 | 用户选择或反馈 | AI诊断及依据 | 实际修订/保留动作 | 当前结果 |
| --- | --- | --- | --- | --- | --- |
| 启动后填写 | 具体到概念、参考或草案 | 保留/修改/搁置，记录原因 | 区分审美取舍与可观察问题 | 只写实际采取的动作 | 已采用/待改/未执行 |

按用户决定继续推进，方向已清晰时不反复确认；有实质取舍时让提案帮助作选择。不要为了补齐模板重生成素材或修改已合格内容。

## 本轮复盘

- 哪个方向被采用，依据是什么；尚未采用时明确记为待定。
- 哪些指导让概念或美术表达更具体，哪些仍然空泛、需要更好的参考或专业反馈。
- 与同Brief下已有方法相比，观察到了什么差异；未对照时不写提升结论。
- 哪些做法值得在下一个任务继续验证，哪些属于本项目取舍。
- 是否有足够实际证据更新SOP或自己的Skill；没有则保留任务记录，暂不固化。
