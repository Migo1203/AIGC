# 音箱规格资料

把产品规格截图、官方功能介绍截图、说明书或 PDF 上传到这个文件夹。

## 建议准备

- 带有商品名称和具体型号的页面截图。
- 供电、连接方式、尺寸等规格信息。
- 主要功能、卖点和适用场景说明。

## 上传方法

1. 在 GitHub 中打开本文件夹。
2. 点击 **Add file → Upload files**，选择截图或资料文件。
3. 点击 **Commit changes** 保存。

文件名可以使用 `spec-page-01.png`、`features-01.png`、`manual.pdf` 等。

核实后的信息填写到 [产品规格整理表](product-specs.md)，并记录依据的文件或页面位置。
