# 音箱产品图片

把音箱的产品主图、实物照片和细节图上传到这个文件夹。

已扫描的上传资料：[小度智能音箱随身版](小度智能音箱随身版/)，共43个文件。原33个文件包含商品宣传图、参数图、页面说明和附属图标；新增10张包含多角度实物照片、套餐图和主图。原批次007与008是完全重复的文件。详见[原始文件索引](../specs/source-index.md)。各图拍摄者、来源和公开使用权限需分别记录，不能仅凭文件名判断。

## 建议准备

- 一张能看清完整外观的主图。
- 正面、侧面、背面或斜侧面的实拍图。
- 按键、接口和材质等细节图。

## 上传方法

1. 在 GitHub 中打开本文件夹。
2. 点击 **Add file → Upload files**，选择图片。
3. 点击 **Commit changes** 保存。

文件名可以使用 `front.jpg`、`side.jpg`、`back.jpg`、`detail-01.jpg` 等。记录每张图片的来源，例如“自己拍摄”或具体来源页面；引用素材时补充可使用的授权说明。

产品参数和功能截图放在 [规格资料](../specs/README.md) 中，方便与外观图片一起核对。
