# Migo的AIGC作品集资料库

集中保存与 AIGC 创作、个人作品集和网站建设有关的信息、学习资料与网站链接。

## 分类入口

| 分类 | 存放内容 | 入口 |
| --- | --- | --- |
| 搜集信息 | 创作灵感、工具资讯、文章要点和实用技巧 | [搜集信息](information/README.md) |
| 学习资料 | 教程、课程、文档、操作方法和学习笔记 | [学习资料](learning/README.md) |
| 参考网站 | 作品集参考、设计灵感、工具网站和其他实用站点 | [参考网站](websites/README.md) |

## 如何添加资料

1. 打开合适的分类入口，点击铅笔图标编辑。
2. 复制该分类中的记录模板，放到“收集记录”小节。首次添加时删除“目前暂无收集条目”。
3. 填写标题、来源链接和简短笔记，再提交保存。

较长的笔记或需要保存的资料文件，可以另放在对应分类目录，并在记录中附上文件链接。

模板只是填写格式。目前还没有添加外部收藏资料，后续按实际来源逐条补充。
